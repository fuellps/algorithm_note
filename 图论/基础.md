### 存储方式

- 链式前向星(邻接表)

用数组模拟链表实现。 **其实就是模拟单链表的头插法。**

h数组存储结点的头结点，e数组边对应的结点，ne数组存储结点的下个点，w数组存储边的边权。

> 注意存储无向图时e数组，ne数组，w数组要开两倍边数大小。

```c++
int e[M<<1],ne[M<<1],w[M<<1],h[N],idx = 1;
// 加边
void add(int u,int v,int c){
    e[idx] = v; ne[idx] = h[u];w[idx] = c; h[u] = idx++;
}
// 遍历u的邻居
for(int ei = h[u]; ei; ei = ne[ei]){
    int v = e[ei];  
    //Todo..
}
```

- 邻居表（可用链表实现）

为了编码简单，可用动态数组实现。如python的List，c++的vector，Java的ArrayList等。

```c++
vector<vector<int>> g(n+1,vector<int>());
g[u].push_back(v); //添加u -> v的边
//遍历u的邻居
for(int v : g[u]){
    //Todo..
}
```

- 邻接矩阵

```c++
vector<vector<int>> g(n+1,vector<int>(n+1));
g[u][v] = 1; //添加u->v的边
//遍历u的邻居
for(int i = 1; i <= n; i++){
    if(g[u][v]){
        //Todo..
    }
}
```
