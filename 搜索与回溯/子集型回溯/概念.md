## 概念

#### 输入的视角（选或不选）：

>  一般定义dfs(i)表示选或不选第i个元素.
>
> 选,从dfs(i+1) + 选择的相关处理.
>
> 不选.从dfs(i + 1) + 不选择的相关处理.

#### 从答案的角度（枚举结束位置）：

> 一般定义dfs(i)表示以i开始的最优值。
>
> 枚举$j \in [i,n)$,考虑是否能从dfs(j)转移而来。

## 模板

用dfs实现可以有两种做法.一种是记录选了哪些状态.一种是记录选了什么.

#### 从输入的视角（选或不选）

```c++
//template1:记录选了什么
path[n];
int si;
void dfs(int i){
    if(i == n){
        //demo 找到一个合法状态
        for(int j =0 ;j < si; j++){
            //相关处理
        }
        return;
    }
    dfs(i+1); //不选
    path[si++] = a[i]; //记录选了什么
    dfs(i+1);
    si--; //还原现场
}


//template2:记录哪些选了
bool st[N];
void dfs(int i){
    if(i == n){
        for(int j = 0;j < n; i++){
            if(st[j]){
                //相关处理
            }
        }
        return;
    }
    dfs(i + 1); //不选
    st[i] = true; //选
    dfs(i + 1);
    st[i] = false; //还原现场
}
```

#### 从答案的视角（枚举选了什么）

```c++
path[n];
int si;
void dfs(int i){
    for(int j = 0;j < i; j++){
        cout << path[i] << " ";
    }
    cout << endl;
    for(int j = i;j < n; j++){
        path[si++] = a[i];
        dfs(j+1);
        si--;
    }
}
```



## 二进制枚举

除了用递归处理,还可以用二进制枚举子集来做.

具体而言,假使有n个数,则有2^n个子集(选或不选).

```c++
for(int i =0;i < 1 << n; i++){//枚举子集:假使有4个数,则i = 1010 表示选第2和第4个数
    for(int j =0 ;j < n; j++){
        if(i>>j & 1){
            //相关处理
        }
    }
}
```
