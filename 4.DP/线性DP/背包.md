# 模板汇总

## 一:01背包

### 最多为target模型

> 前言:01背包问题是指有n个物品,第i个物品体积为w[i],价值为v[i],每个物品只能选1次,能装入体积为V的背包的最大价值是多少?

$$
\begin{aligned}
&状态表示:定义dp[i][j]表示从前i个物品中选，总体积不超过j所能得到的最大价值 \\
&可得状态转移方程为: dp[i][j] = max(dp[i-1][j],dp[i-1][j-v[i]]) +w[i] \quad(j \ge v[i]) \\
&边界条件:i<0时,没有数可以选,体积不超过j的最大价值为0. \\
&初始化: \sum^{m}_{j=0}dp[0][j] = 0,表示没有物品时总体积不超过j的最大价值为0 \\
&由于上述方程只依赖于i-1这一行，因此可以利用滚动数组进行优化，\\
&进一步，由于j-v[i]\le j,因此可以只用一维数组进行滚动更新即可。 \\
\end{aligned}
$$

> 一维数组01背包框架：

```java
for(int x : nums){ //枚举物品
   for(int j = V; j >= x; j--){ //枚举体积
       dp[j] = f(dp[j],dp[j-x]); //f代表题目中的要求
   } 
}
```

### 恰好为target模型

$$
\begin{aligned}
&状态表示:dfs(i,j)表示从下标0到下标i中选择,得到的子序列和恰好为j的最大价值(具体题目不同定义) \\
&可得状态转移方程为: dp[i][j] = max(dp[i-1][j],dp[i-1][j-v[i]]) +w[i] \quad(j \ge v[i]) \\
&边界条件:i<0时,如果j==0返回0,状态合法.否则返回-inf,表示状态不合法. \\
&初始化:dp[0][0]=0, \sum^{m}_{j=0}dp[1][j] = -inf,表示只有从前0个物品中选只有体积为0的状态合法 \\
&由于上述方程只依赖于i-1这一行，因此可以利用滚动数组进行优化，\\
&进一步，由于j-v[i]\le j,因此可以只用一维数组进行滚动更新即可。 \\
\end{aligned}
$$



```java
	int s  = 0;
	for(int x : nums){
        s += x;
        //优化:只枚举前缀和目标和中的最小值
        for(int c = Math.min(s,target); c >= 0; c--){
            dp[c] = f(dp[c], dp[c-x]);
        }
    }
```



### 至少为target模型

$$
\begin{aligned}
&状态表示:定义dp[i][j]表示从前i个数中选,组合成的元素和至少为j的方案数(具体题目不同定义) \\
&可得状态转移方程为: dp[i][j] = dp[i-1][j] + dp[i-1][max(j-v[i],0)] \\
&边界条件:i<0时,如果j \le 0 返回1,找到一种方案.否则返回0,表示没有找到方案. \\
&注意上述max(j-v[i],0),这必须保证原始价值没有非负数,则至少为负数的方案数等价于至少为0的方案数\\
&进一步，由于j-v[i]\le j,因此可以只用一维数组进行滚动更新即可。 \\
\end{aligned}
$$



```java
//求和至少为target的方案数
dp[0] = 1;
for(int x : nums[i]){
    //为什么这道题背包容量可以到达0而不是到达x? 这是因为dp数组的定义是`至少`,而不是`恰好`,至少为x也满足至少为0,因此0是1个合法的状态,就应该被计算得到.
    //背包的容量可以到0
    for(int c = t; c >= 0; c--){
        dp[c] += dp[Math.max(c-x,0)]; 
    }
}
```

### 常数优化

对于01背包问题，一个常数优化的做法是维护物品体积的前缀和 $s$,遍历时只需遍历背包容量为 $min(s,V)$即可。这是因为前面的物品最多只能凑出s，如果求最多价值和(s,V]这段区间的内容和s是一致的，如果是求恰好那么都是不满足的状态。

> 注意：如果用这种写法求标准的01背包问题，最后需要遍历dp数组求最大值。因为`dp[n][m]`不一定会被遍历到。

## 二:完全背包

> 有n种物品,第i个物品的体积为w[i],价值为v[i],每种物品可以选择无限个,求装入背包容量为W的最大价值.

$$
\begin{aligned}
&类似于01背包，我们可以定义dp[i,j]表示从前i个物品中选,总体积不超过W的最大价值,\\
&枚举第i个物品选几个，则dp[i,j] =max(dp[i-1,j],dp[i-1,j-\sum_{k=1}^{x}k*v_i]+k*w_i) \\
&x为满足 x*v_i \le j的最大正整数。\\
\end{aligned}
$$



$定义dp[i][j]表示前i个物品中选,体积不超过W的最大价值.$

$子问题?不选第i个物品,从dp[i-1][j]转移而来$

$j >= w[i],可以选第i个物品,从dp[i][j-w[i]]转移而来$

$当i < 0时,没有物品可以选,此时背包为空,返回0$

```java
//代码示例
for(int i = 0;i < n; i++){
    for(int j = w[i]; j <= W; j++){
        dp[i+1][j] = dp[i][j];
        if(j >= w[i]){
            dp[i+1][j] = Math.max(dp[i+1][j],dp[i+1][j-w[i]] + v[i]);
        }
    }
}

//空间优化:
for(int i = 0;i < n; i++){
    for(int c = w[i]; c <= W; c++){
        dp[c] = max(dp[c], dp[c-w[i]] + v[i]);
    }
}

```



## 三:多重背包

> 有n种物品,每种物品能选$cnt_i$个,每种物品的体积为$v_i$,价值为$w_i$,在体积不超过m的情况下,求所能得到的最大价值

可以把选择第i个物品选 $k_i$个转化为有 $有k_i$个相同的物品，每个物品只能选择一次。

### 朴素版本

```c++
int multipleBackpack(){
    for(int i  =0;i < n; i++){
        for(int j = m; j >= 0; j--){
            for(int k = 0;k*v[i] <= j && k <= cnt[i];k++){
                dp[j] = max(dp[j],dp[j-k*v[i]] + k*w[i]);
            }
        }
    }
    return dp[m];
}
```

### 二进制分组优化

```c++
int multipleBackpack{
    cin >> n >> m;
    for(int i = 0,x,volume,weight; i <n; i++){
        //读入每个物品的体积，价值，次数。
        cin >>  volume >> weight >> x;
        for(int k = 1;k <= x; k<<=1){//进行二进制拆分，直到s为空或者剩下一个余数
            v[cnt] = k*volume,w[cnt] = k*weight;
            x -= k;
            cnt++;
        }
        if(x > 0){
            v[cnt] = x*volume,w[cnt] = x*weight;
            cnt++;
        } 
    }
    //分解后就可视为01背包问题。
    for(int i  =0;i < cnt; i++){
        for(int j = m;j >= v[i]; j--){
            dp[j] = max(dp[j], dp[j-v[i]] + w[i]);
        }
    }
    return dp[m]
}
```

### 单调队列优化

- 按照体积分组进行更新，可以发现更新的范围不能超过物品的个数，因此可以用单调队列优化。

```c++
sc("%d%d",&n,&m); //读入物品种类和背包总体积
for(int i =0;i < n; i++){
    int w,v,s;sc("%d%d%d",&v,&w,&s); //读入价值，体积，个数 
    memcpy(g,f,sizeof (f));
    for(int j = 0;j < w;j++){ //枚举余数 
        l = r=  0;
        for(int k = j;k <= m; k+=w){ //按体积更新 
            while(l < r && g[q[r-1]] + (k-q[r-1])/w*v < g[k]) r--; //去除无用的队尾 
            q[r++] = k;
            if(q[l] < j - v*s) l++; //超过个数，队头出队
            f[k] = g[q[l]] + (k-q[l])/w*v;
        }
    }
}
cout << f[m] << endl; 
```



## 四:分组背包

$$
\begin{aligned}
&分组背包有两种常见类型. \\
&每个组必须选1个.若进行空间压缩,则在计算当前背包容量前\\
&需要将当前枚举到的背包容量状态值置为初始态.对于无法到达的状态,也需要置为初始态.\\ 
\\
&每个组至多选1个.若进行空间压缩,则不需要进行置为初始态.\\
&因为前当前分组一个都不选的状态不会影响当前 \textbf{每个组至多选1个}的状态方程
\end{aligned}
$$




> 有n个袋子,每个袋子有m个物品,第i个袋子的第j个物品的价值为v[j],体积为w[i],在容量不超过W的背包中,返回你能获得的最大价值.
>
> !!!注意这个题意是每个袋子都必须选1个.不能从什么都不选的状态转移而来.



$$
\begin{aligned}
&定义dfs(i,j)表示在前i个组中恰好选1个物品,体积不超过j所能得到的最大价值 \\
&遍历每一个组中的物品，考虑组内的物品选或不选 \\
&选，则需要满足j \ge x,则可从dfs(i-1,j-x)转移而来 \\
&不选，则从dfs(i-1,j)转移而来 \\
&边界条件：i < 0 时返回0
\end{aligned}
$$


```c++
//无空间压缩的分组背包模板
for(int i = 0;i < n; i++){ //枚举第几个物品组
    for(int j = 1;j <= m; j++){//枚举背包体积
        for(int k =0 ;k < a[i]; i++){//枚举组内物品
            int v = b[i][k],w=c[i][k]; //物品的体积和价值
            if(j >= v){
                dp[i][j] = max(dp[i][j],dp[i-1][j-v] + w);
            }else{
                dp[i][j] = dp[i-1][j];
            }
        }
	}
}


//空间优化的分组背包模板
for(int i = 0;i < n; i++){ //枚举第几个物品组
    for(int j = m; j; j--){//枚举背包体积
        for(int k =0 ;k < a[i]; i++){//枚举组内物品
            int v = b[i][k],w=c[i][k]; //物品的体积和价值
            if(j >= v){
                dp[j] = max(dp[j],dp[j-v] + w);
            }
        }
	}
}
```
