### 模板

用于在一个字符串的字母异位词中找到最小的字典序位置。

例如“abac”的字母异位词为“baca”,”acab”,”caba”.

###### 算法流程

- 使用三指针，i指向第一个字符，j指向第二个字符，k指向长度(一开始为0)
- 比较s[i+k]与s[j+k]的字典序大小，若s[i+k]>s[j+k],则i=i+k+1,否则j = j + k + 1
- 循环结束,min(i,j)即为答案

```c++
int get_min(const string& t){
    string s =  t + t;
    int i = 0,j = 1;
    int n = t.size();
    while(i < n && j < n){
        for(l=0;k<n&&s[i+k] == s[i+k]; k++);
        s[i+k] > s[j+k] ? i = i + k + 1 : j = j + k + 1;
        if(i == j) j++;
    }
    return min(i,j);
}
```
