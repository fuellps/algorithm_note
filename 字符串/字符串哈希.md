### 字符串哈希

通过哈希映射快速判断两个字符串是否相同,基于进制哈希还可以判断任意子串是否相同.

### 性质

1. 在 Hash 函数值不一样的时候，两个字符串一定不同；
2. 在 Hash 函数值一样的时候，两个字符串可能不同(可能出现哈希冲突,导致判断失败)

### 算法

通常采用多项式哈希,即 $f(s) = \sum_{l=1}^{n} s[l]*b^{n-l} \pmod p$

#### 求任意子串的哈希

$$
\begin{aligned}
&令ha[i]表示s[:i]的哈希值,则ha[i] = s[1]*b^{i-1} + s[2]*b^{i-2} + \dots s[i]  \pmod p \\
&假设要求ha[l:r],则有ha[l:r] = ha[r] - ha[l-1]*b^{r-l+1} \\
\because\ &ha[r] = s[1]*b^{r-1} + s[2]*b^{r-2} + \dots s[r]  \pmod p \\
&ha[l-1]*b^{r-l+1}=s[1]*b^{r-1}+s[2]*b^{r-2}+\dots s[l-1]*b^{r-l+1} \pmod p \\
\therefore\ &ha[r] - ha[l-1]*b^{r-l+1} = s[l]*b^{r-l}+s[l+1]^{r-l-1}+\dots+s[r] \pmod p 

\end{aligned}
$$



```c++
// 模板:
struct Hash{
	const int M1 = 1070777777; //M1,M2为模数
    const int M2 = 1e9 + 7;
    const int b1 = 131,b2 =233;//b1,b2为base值,即进制
    vector<int> h1,p1,h2,p2;//h1,h2表示前缀多项式哈希值,p1,p2为base进制的次方结果
    
    Hash(const string& s){
        int n = s.size();
        h1.resize(n+1),h2.resize(n+1),p1.resize(n+1),p2.resize(n+1);
        p1[0] = p2[0] = 1;
        for(int i = 0;i < n; i++){
        	h1[i+1] = ((ll)h1[i]*b1+s[i])%M1;
        	h2[i+1] = ((ll)h2[i]*b2 + s[i])%M2;
        	p1[i+1] = (ll)p1[i]*b1%M1;
        	p2[i+1] = (ll)p2[i]*b2%M2;
		}
    }
    ll query(int l,int r){//{hash1,hash2}对应双模哈希的结果.
    	int m = r - l + 1;
    	int res1 = ((h1[r] - (ll)h1[l-1]*p1[m])%M1 + M1)%M1;
    	int res2 = ((h2[r] - (ll)h2[l-1]*p2[m])%M2 + M2)%M2;
    	return res1<<32|res2;
	}
};
```

$$
有几个点可以优化: \\
①进制的power数组可以放在外面,这样不用一直重复计算.\\
②由于取模运算常数时间很大,在某些情况下会造成TLE,可以让其自然溢出,但是容易被卡\\
$$
