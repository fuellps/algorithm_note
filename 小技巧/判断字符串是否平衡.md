$定义一个字符串s="abab"是平衡串,即当前仅当s中每个字符出现的次数是一样的$



> 一开始我的思路是统计每个字符出现的次数,然后再开一个哈希表统计出现次数的次数.如果另一个哈希表的长度为1,则满足条件.

```java
		int[] cnts = new int[1_001];//统计出现次数为i的字符的个数
        int[] cnt = new int[26];//统计每个字符出现的次数
        int diff = 0; //统计有多少个不同的出现次数
        for(int i = 0;i < n; i++){
            Arrays.fill(cnt,0);
            Arrays.fill(cnts,0);
            diff = 0;
            for(int j = i; j >= 0; j--){
                int count = cnt[s[j] - 'a']++;
                cnts[count+1]++;
                if(cnts[count] > 0){//如果原来的次数已经出现,需要减去
                    if(--cnts[count] == 0){//如果刚好减为0,哈希表长度减1
                        diff--;
                    }
                }
                 if(cnts[count+1] == 1){//如果当前出现次数的次数为1,则哈希表长度要加1
                    diff++; //说明当前新增了一个出现次数为count+1的字符
                }
                if(diff == 1){
                    dp[i+1] = Math.min(dp[i+1],dp[j] + 1);
                }
            }
        }
```
