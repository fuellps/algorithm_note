### 下标依赖关系的打家劫舍

这种题一般是求在一个数组中不能选择连续的数,求能得到的数组最大和.例如打家劫舍,当偷下标为i的房子时,不能偷下标为i-1和下标为i+1的房子.



$$
\begin{aligned}
&定义dfs(i)表示从下标0到i中偷,能得到的最大价值.\\
&分类讨论：\\
&当前操作可以偷第i号房子,则可以获得第i间房子的价值加上偷前i-2个房子的最大价值。\\
&或者不偷第i号房子,则从偷前i-1个房子的最大价值转移而来\\
&两者取最大值,即为当前子问题的答案.即dfs(i)=max(dfs(i-2)+nums[i],dfs(i-1));\\
\end{aligned}
$$


对于下标连续的打家劫舍类型,可以进行空间压缩.

```java
//记忆化搜索代码:
 int dfs(int i,int[] nums,int[] dp){
     if(i < 0) return 0; //没有房子可以偷
     if(dp[i] != -1) return dp[i];
     return dp[i] = Math.max(dfs(i-1,nums,dp),dfs(i-2,nums,dp) + nums[i]);
 }
```





每个状态只依赖于前两个状态,因此只需定义两个变量滚动更新即可.

```java
//假设数组为nums,数组长度为n
//没有空间优化的代码:对dfs()1:1翻译
int[] dp = new int[n+2];//插入两个状态,避免边界讨论.
for(int i = 0;i < n; i++) dp[i+2] = Math.max(dp[i] + nums[i],dp[i+1]);
return dp[n+1];

//空间优化的代码:
int f0 = 0,f1 =0; //边界状态都为0
for(int i = 0; i < n; i++){
    int new_f = Math.max(f0 + nums[i],f1);
    f0 = f1;
    f1 = new_f;
}
return f1;
```

### 值域型依赖的打家劫舍

对于**值域型打家劫舍**,比较好写是用哈希表统计次数,并用一个数组记录下键,对数组进行排序后就相当于在下标型依赖的打家劫舍.

解题思路:
$$
\begin{aligned}
&定义dp[i]表示从去重后的数组中前i个下标开始选所能得到的最大价值.\\
&假设值域限制为k,即选了nums[i],则不能选nums[i] -k,nums[i]-k+1,...nums[i]+k的值\\
&考虑最后一个元素选或不选:\\
&选,则从dp[j] + 选第i个元素所能得到的价值(其中j是满足nums[j] < nums[i] - k的最大下标)\\
&不选,则从dp[i-1]转移而来
\end{aligned}
$$
##### **技巧:**

由于数组已经有序,随着i的增大,j必然也增大,因此可以用双指针找到第一个大于等于nums[i] - k的数,则dp[i]可以从dp[j-1] + 选第i个元素所能得到的价值 转移而来



```java
//假设数组为nums,数组长度为n
Map<Integer,Integer> dict = new HashMap<>();
for(int x : nums) dict.merge(x,1,Integer::sum); //dict[x]++;
int si = dict.size();
int k = 0;
int[] a = new int[si];
for(int x : dict.keySet()) a[k++] = x;
Arrays.sort(a);
long[] dp = new long[si+1]; //插入一个状态,避免边界讨论
//双指针,找到一个j是最小的满足nums[j] >= nums[i] - 2
int j = 0;
for(int i = 0;i < si; i++){
    while(a[j] < a[i] - 2) j++;//找到一个j是最小的满足nums[j] >= nums[i] - 2
    dp[i+1] = Math.max(dp[i],dp[j] + nums[i]);
}
return dp[si];
```

也可以不用哈希去重。以双指针形式去重。

```python
class Solution:
    def maximumTotalDamage(self, power: List[int]) -> int:
        power.sort()
        n = len(power)
        i = j = 0
        dp = [0]*(n + 1)
        while i < n :
            start = i
            i += 1
            while i < n and power[i] == power[i-1]: i += 1
            while power[j] < power[start] - 2: j += 1
            dp[i] = max(dp[j] + (i- start )*power[start], dp[start])
        return dp[n] 
```
