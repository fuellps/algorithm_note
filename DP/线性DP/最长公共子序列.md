## 概念

这类题目一般是与**子序列匹配有关的问题**
$$
前言:对于两个字符串的子序列\textbf{匹配}问题,\\一般定义dfs(i,j)表示s中下标从0到i,与t中下标从0到j的..处理结果\\
一般根据题意,考虑第i个字符与第j的字符是否匹配,做相应处理.\\
递归边界:i < 0 或 j < 0,表示其中某个字符串为空,根据题意做相关处理
$$



给你两个字符串s,t,求s和t的最长公共子序列长度

$定义dp[i][j]表示s中前i个字符与t中前j个字符的最长公共子序列长度$

$子问题?贪心的想,如果s[i]=t[j],那么肯定选当前字符的子序列长度最好.因此从dfs(i-1,j-1)+1转移而来$

$如果s[i]!=s[j],那么就只不选1个字符,从max(dfs(i-1,j),dfs(i,j-1))转移而来$

$边界条件:i <0 || j < 0,表示其中1个字符串为空,则最长公共子序列长度为0$

```java
//经典模板：
int[][] dp = new int[n+1][m+1];//个插入1个状态,规避边界讨论
//初始化:全为0,因此默认值就是初始化值
for(int i = 0; i < n; i++){
    for(int j = 0;j < m; j++){
        if(s[i] == t[j]){
            dp[i+1][j+1] = dp[i][j] + 1;
        }else{
            dp[i+1][j+1] = max(dp[i+1][j], dp[i][j+1]);
        }
    }
}


//空间优化:每个状态依赖于上面的格子,左上角的格子,左边已经计算好的格子->(内层循环需正序遍历)
int[] dp = new int[m + 1];//默认值就是边界值
for(int i = 0;i < n; i++){
    int prev = dp[0];
    //有些题目需要在这里更新dp[0]的值
    for(int j = 0; j < m; j++){
        int tmp = dp[j+1]; //保存下一个左上角的值
        if(s[i] == t[j]){
            dp[j+1] = prev + 1;
```

```c++
//空间优化版本
void solve() {
    int mod = 1e9 + 7;
    string s1,s2; cin >> s1 >> s2;
    n = s1.size()-1,m=s2.size()-1;
    vector<int> lcs(m+1);
    vector<vector<ll>> f(2,vector<ll>(m+1));
    std::fill(f[0].begin(), f[0].end(),1);
    for(int i =0 ;i < n; i++){
        fill(f[i+1&1].begin(),f[i+1&1].end(),0);
        f[i+1&1][0] = 1;
        char c1 = s1[i];
        int pre = 0; //lcs[i][0]
        for(int j = 0;j < m; j++){
            int tmp = lcs[j+1];
            char c2 = s2[j];
            if(c1 == c2){
                lcs[j+1] = pre + 1;
                f[i+1&1][j+1] = f[i&1][j];
            }else{
                lcs[j+1] = max(lcs[j],lcs[j+1]);
            }
            if(lcs[j+1] == lcs[j]) f[i+1&1][j+1] += f[i+1&1][j]; //从不选c2,选c1转移而来
            if(lcs[j+1] == tmp) f[i+1&1][j+1] += f[i&1][j+1];//从不选c1,选c2转移而来
            if(c1 != c2 && lcs[j+1] == pre) f[i+1&1][j+1] -= f[i&1][j];//去除重复贡献。
            f[i+1&1][j+1]%=mod;
            pre = tmp;
        }
    }
    cout << lcs[m] << endl << f[n&1][m] << endl;
}

int main() {
    ios::sync_with_stdio(0), cin.tie(0), cout.tie(0);
    solve();
    return 0;
}
```
