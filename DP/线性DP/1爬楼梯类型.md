### 思路

$$
\begin{aligned}
&定义dp[i]表示到达第i层的方案数\\

&假设有n种移动方式.nums[j]为移动的步数.则\\

&假使我们选择地j种方式,则到达第i层依赖于到达i - nums[j]层的方案数,\\
&由于不可能同时选择不同方式到达第i层,所以移动方式相互独立,满足加法定理.\\

&则dp[i] = \sum_{j=1}^{n}dp[i-nums[j]] \\
&边界条件:一般当i =0时,返回1.表示恰好找到一种合法方案.或者可以理解为停在原地也是一种方案.
\end{aligned}
$$



```java
//记忆化搜索
int dfs(int i,int[] nums,int[] dp){
    if(i == 0) return 1;
    if(dp[i] != -1) return dp[i];
    int res = 0;
	for(int x : nums[i){
        if(x <= i){
            res += dfs(i-x,nums,dp); //可以由i-x转移而l
        }
    }
    return dp[i] = res;
}
```



#### 注意事项:

1.对于确定的移动方法,爬到第i阶楼梯的方法数是确定的.所以可以先预处理1-MaxLen阶台阶的方案数.

2.如果是用记忆化来求[minLen,maxLen]阶楼梯的数量,应该这样写:

```java
//正确写法:	
for(int i = minLen;i <= maxLen; i++){
    ans = (ans + dfs(i))%mod; //方案数可能很大,一般要求取模
}

//错误写法:
dfs(maxLen);
for(int i = minLen;i <= maxLen; i++){
    if(dp[i] != -1)
    ans = (ans + dp[i])%mod; //方案数可能很大,一般要求取模
}
```

上面的错误写法只考虑了爬到第maxLen阶台阶.有可能本来maxLen-1等阶台阶能到达,但因为从maxLen阶台阶开始向前移动,导致maxLen-1等台阶移动不到,导致方案数变少.

也可以这样理解,直接先从最大的状态开始递归,需要求的状态对应的记忆数组可能已经发生改变,这样就不符合记忆化的要求.都还没求,记忆化数组不能更改.

3.爬楼梯问题**本质上是一个排列问题.**相当于在一些可重复的数中选,凑成一个数的不同排列的方案数/最小代价等问题.因为外层循环枚举数字,内层循环枚举转移的数字,相当于在前面排列的基础上进行新的排列.
