爬楼梯类型本质是从0开始构造,通过一些方式(加上某些数字),返回到达到某个数的方案数.

一般定义dfs(i)表示从0开始构造,到达i的方案数

假设有n种移动方式.nums[j]为移动的步数.则

子问题为:$\sum_{j=1}^{n}dfs(i - nums[j])$

即:$ dfs(i)=\sum_{j=1}^{n}dfs(i - nums[j])$

```java
//记忆化搜索
int dfs(int i,int[] nums,int[] dp){
    if(i == 0) return 1;
    if(dp[i] != -1) return dp[i];
    int res = 0;
	for(int x : nums[i]){
        if(x <= i){
            res += dfs(i-x,nums,dp); //可以由i-x转移而l
        }
    }
    return dp[i] = res;
}
```



注意事项:

1.对于确定的方法,爬到第i阶楼梯的方法数是确定的.所以可以先预处理1-MaxLen阶台阶的方案数.

2.如果是用记忆化来求[minLen,maxLen]阶楼梯的数量,应该这样写:

```java
//正确写法:	
for(int i = minLen;i <= maxLen; i++){
    ans = (ans + dfs(i))%mod; //方案数可能很大,一般要求取模
}

//错误写法:
dfs(maxLen);
for(int i = minLen;i <= maxLen; i++){
    if(dp[i] != -1)
    ans = (ans + dp[i])%mod; //方案数可能很大,一般要求取模
}
```

上面的错误写法只考虑了爬到第maxLen阶台阶.有可能本来maxLen-1等阶台阶能到达,但因为从maxLen阶台阶开始向前移动,导致maxLen-1等台阶移动不到,导致方案数变少.

也可以这样理解,直接先从最大的状态开始递归,需要求的状态对应的记忆数组可能已经发生改变,这样就不符合记忆化的要求.都还没求,记忆化数组不能更改.
