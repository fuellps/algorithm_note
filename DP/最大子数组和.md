对于子数组最大和,一般定义dfs(i)表示以i结尾的子数组最大和.

$$
子问题? 和以i-1结尾的子数组拼起来形成新的子数组\\

不和i-1结尾的子数组拼起来,自己单独作为子数组\\

即dfs(i)=max(dfs(i-1)+nums[i],nums[i])=max(dfs(i-1),0)+nums[i]\\
$$

> 注意:这个状态方程只依赖于前一个状态,每个状态只会访问一次,因此不会由重复访问的情况.因此只需普通递归就行,不需要开记忆化数组.

```java
//递归:下面代码求整个数组的最大子数组和
//对于每个以i结尾的子数组都需要求一次最大子数组和
int ans; //整个数组的最大子数组和
int dfs(int i,int[] nums){
    if(i == 0) return ans = nums[0];
    int res = Math.max(dfs(i-1),0) + nums[i];
    ans = Math.max(ans, res);
    return res;
}
```

```java
//动态规划代码
int dp = new int[nums.length];
int ans = dp[0] = nums[0];
for(int i = 1;i < nums.length; i++){
    dp[i] = Math.max(dp[i-1],0) + nums[i];
    ans = Math.max(ans,dp[i]);
}
return ans;
```

>  空间优化:每个状态只依赖于前一个状态,因此只需一个变量来滚动更新即可.

```java
int ans,f0;
ans = f0 = nums[0];
for(int i = 1; i < nums.length; i++){
    f0 = Math.max(f0,0) + nums[i];
    ans = Math.max(ans,f0);
}
return ans;
```

扩展题目:

$1.数组可以串联k次,意思是当前数组是原数组从什么都没有拼接k次的结果$
$$
\begin{flalign}
&\text{分类讨论:}&\\
&\text{1.当k=1时,相当于求一次数组最大子数组和s1}&\\
&\text{2.当k=2时,相当于求两次数组最大子数组和s2}&\\
&\text{当k>2时,设原数组前缀和为s.}&\\
&\text{若s>0,则当前数组最大子数组和为 s2+(k-2)*s}&\\
&\text{若s<0,则当前数组最大子数组和为 s2}&\\
\end{flalign}
$$



>  说明:如果s>0,那么当前数组最大子数组和至少为s*k,而由于负数的存在,前两个数组的子数组之和可能大于s\*2,因此最大子数组之和为 s2+(k-2)*s

$2.求环型数组的最大子数组之和$

$分类讨论:1.如果最大子数组在中间,那么就只需用dp求出最大子数组即可$

$2.如果最大子数组在原数组不连续,由于最小连续子数组和+其余元素=数组原数组.\\因此只需要求出最小连续子数组,再用数组和减去即可$

对于一个环型数组,可以将器最大子数组和看作是一段连续的最大子数组和,记为$maxS$,或者是一段不连续的最大子数组之和.对于不连续的最大子数组之和,只需求出最小的连续子数组之和,记为$minS$,再用数组的前缀和,记为$s$减去最小连续子数组之和即可.

> 注意:有可能出现最小连续子数组之和等于数组的前缀和s,这时不连续的最大子数组之和就会为空.因此如果要求子数组不能为空的话,应该特判最小连续子数组和是否等于前缀和,如果是的话,答案就是maxS.否则为max(maxS,s - minS)

$3.最大乘积和$

$定义dfs(i)表示以i结尾的最大乘积$

$子问题?由于存在负数,因此需要知道以i-1结尾的最大乘积maxM,和以i-1结尾的最小乘积minM.$

$则若拼接以i-1的子数组,则当前问题答案为max(nums[i-1]*minS,nums[i]*maxS)$

$自己单独作为一个子数组,则当前问题答案为nums[i]$

$两者取最大值,即为当前的答案.$

```java
//对于min,max的更新: 必须保证更新时min,max都是先前的数
int new_max = Math.max(nums[i],Math.max(nums[i]),Math.max(nums[i]*min,nums[i]*max));
min = Math.min(nums[i],Math.min(nums[i]*min),Math.min(nums[i]*max)) 
max = new_max;
```
