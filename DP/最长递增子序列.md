$最长递增子序列是有数值元素相邻位置依赖的,所以一般用枚举选哪个的思路$

$做法1:定义dp[i]表示以i结尾的最长递增子序列$

$子问题?枚举j < i,如果nums[j]< nums[i],那么dp[i] = max(dp[i],dp[j+1])$

```java
int ans = 0; //记录数组中的最长递增子序列
int[] dp = new int[n];
for(int i = 0;i < n; i++){
    dp[i] = 1; //以i结尾的最长递增子序列的长度至少为1
    for(int j = 0;j < i ; j++){
        if(nums[j] < nums[i]){
            dp[i] = Math.max(dp[i], dp[j] + 1);
        }
    }
    ans = Math.max(ans,dp[i]);
}
return ans;
```

$做法2:定义f[i]表示长度为i+1的最长递增子序列的末尾元素$

$贪心的想,要使最长递增子序列越长,则最长递增子序列前一个元素尽可能越小越好$

$因此每次查找一个数,就在f数组中找到第一个大于等于他的数,如果找到就替换,\\找不到说明当前数能组成更大长度的最长递增子序列$
