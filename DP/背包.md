

## 一:01背包

> 前言:01背包是有n个物品,第i个物品体积为w[i],价值为v[i],每个物品只能选1次,能装入体积为W的背包的最大价值是多少?

$一般状态方程为:dp[i][j] = f(dp[i-1][j], dp[i-1][j-nums[i]] \quad 其中j >= nums[i])$

$表示在下标0-i中选,物品总重量不超过t时的...性质$

$每个状态依赖于上方的格子,和上方左边的格子.如果压缩成一个数组的话,需要逆序遍历$

$因为正序遍历会先更新上方左边的格子,下一个状态再更新时就不只选了1个物品了.$

```java
for(int x : nums){
   for(int c = target; c >= x; c--){
       dp[c] = f(dp[c],dp[c-x]); //f代表题目中的要求
   } 
}
```







### 恰好为target模型

$一般定义dfs(i,c)表示从下标0到下标i中选择,得到的子序列和恰好为c的..$

$注意01背包当递归到只有1个物品时,还不能终止,因为不一定就要选第一个物品$

$如果是求最大/最小值,当i <0时,如果c!= 0,那就返回inf/-inf,表示方案不合法$

$如果是求方案数,当i <0时,如果c!=0,就返回0,表示方案数为0$

$小优化:假设数组前2个数之和为5,那么合法的状态只有0-5,因此枚举时只需从min(s,target)开始$

```java
	int s  = 0;
	for(int x : nums){
        s += x;
        //优化:只枚举前缀和目标和中的最小值
        for(int c = Math.min(s,target); c >= 0; c--){
            dp[c] = f(dp[c], dp[c-x]);
        }
    }
```



### 判断子序列之和能否组成某个数

$定义dp[i][j]表示在前i个数中选,能否组成j.由于使用空间压缩,所以会把所有能组成的数都算出来.$

```java
基本模板
boolean dp = new boolean[t + 1]; //t为要求的最大范围
dp[0] = true;
for(int x : nums){
    for(int c = t; c >= x; c--){
        dp[c] |= dp[c-x];
    }
}
```



### $至少为target模型$

$定义dp[i][j]表示从前i个数中选,组合成的元素和至少为j的...性质$

$子问题? 不选第i个数,从dp[i-1][j]转移而来$

$选第i个数,从dp[i-1][j-nums[i]]转移而来$

$!!!由于负数也是要记录的状态,但dp数组没有用负数表示方法,如果是求方案数的话,可以累加到dp[0]中\\否则可以根据某些条件特判$

```java
//求和至少为target的方案数
dp[0] = 1;
for(int x : nums[i]){
    //为什么这道题背包容量可以到达0而不是到达x? 这是因为dp数组的定义是`至少`,而不是`恰好`,至少为x也满足至少为0,因此0是1个合法的状态,就应该被计算得到.
    //背包的容量可以到0
    for(int c = t; c >= 0; c--){
        dp[c] += dp[Math.max(c-x,0)]; 
    }
}
```

## $二:完全背包$

> 有n种物品,第i个物品的体积为w[i],价值为v[i],每种物品可以选择无限个,求装入背包容量为W的最大价值.

$定义dp[i][j]表示前i个物品中选,体积不超过W的最大价值.$

$子问题?不选第i个物品,从dp[i-1][j]转移而来$

$j >= w[i],可以选第i个物品,从dp[i][j-w[i]]转移而来$

$当i < 0时,没有物品可以选,此时背包为空,返回0$

```java
//代码示例
for(int i = 0;i < n; i++){
    for(int j = w[i]; j <= W; j++){
        dp[i+1][j] = dp[i][j];
        if(j >= w[i]){
            dp[i+1][j] = Math.max(dp[i+1][j],dp[i+1][j-w[i]] + v[i]);
        }
    }
}

//空间优化:
for(int i = 0;i < n; i++){
    for(int c = w[i]; c <= W; c++){
        dp[c] = max(dp[c], dp[c-w[i]] + v[i]);
    }
}

```

## 四:分组背包

$$
分组背包有两种常见类型.\\每个组必须选1个.若进行空间压缩,则在计算当前背包容量前\\需要将当前枚举到的背包容量状态值置为初始态.对于无法到达的状态,也需要置为初始态.\\ \\
每个组至多选1个.若进行空间压缩,则不需要进行置为初始态.\\因为前1个分组不选的状态不会影响当前"每个组至多选1个"的状态方程
$$




> 有n个袋子,每个袋子有m个物品,第i个袋子的第j个物品的价值为v[j],体积为w[i],在容量不超过W的背包中,返回你能获得的最大价值.
>
> !!!注意这个题意是每个袋子都必须选1个.不能从什么都不选的状态转移而来.



$定义dfs(i,j)表示在前i个袋子中选(1个物品!!!),体积不超过j所能得到的最大价值$

$子问题?枚举袋子的物品体积为x,价值为v,则从dfs(i-1,j-v)转移而来$

```java
int[][] dp = new int[n+1][t+1];//多插入1个状态
//初始化:体积不超过0的最大价值为0,因此默认值即为初始化值.
for(int i = 0;i < n; i++){
    for(int j = 0; j <= t; j++){
        for(int x : w){
            if(j >= x){
                dp[i+1][j] = Math.max(dp[i+1][j],dp[i][j-x] + v[i]);
            }
        }
    }
}


//空间优化:
for(int i = 0;i < n; i++){
```
