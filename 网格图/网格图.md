## $网格图dfs$

判断连通块的个数,大小等.

$一般的通用做法是将越界作为边界条件,这样在调用dfs函数无需判断边界.$

$另外,网格图dfs可能会重复访问同一个格子,通用做法是用vis数组进行判断$

对于在边界需要特殊处理的问题,一般可以用一个布尔变量标记是否是在边界.

```java
//例题:求不能在第一行/列,最后一行/列,且不与0相邻的最大的连通块.数字范围为0~5,相邻的数字构成连通块
	boolean outOfBound;
	for(int i  = 1; i < n - 1; i++){
        for(int j = 1;j < m + 1; j++){
            //直接从中间统计,因为第一行第一列已经不满足条件
            if(g[i][j] >= 1 && g[i][j] <= 5){
                outOfBound = false;
                int res = dfs(i,j,g[i][j], g);
                if(!outOfBound){//没有处在边界或与0相邻
                    ans = Math.max(ans,res);
                }
            }
        }
    }


	int dfs(int i,int j,int c,int[][] g){
        if(i < 0 || j < 0 || i == g.length || j == g[0].length || g[i][j] = '0'){
            outOfBound = true;
            return 0;
        }
          //如果访问到不是同属于一个连通块,或者前面已经访问过了,剪枝.
        if(g[i][j] != c) return 0;
        
        //标记为数组中未存在的值,避免重复访问.也可用布尔数组代替.
        g[i][j] = 6;
             
  //因为每个格子都往四周试探,所以如果有格子在第一行/列,最后一行/列,且与0相邻, 则一定会被遍历到
        return 1 + dfs(i-1,j,g) + dfs(i,j-1,g) + dfs(i+1,j,g) + dfs(i,j+1,g);
    }
```
