- 给定两个有序数组a,b,对于数组a中的每一个数x,找是否存在一个数y,满足$|x-y|<=k$,返回满足的数量

<details>
    <summary>
    	点我查看思路
    </summary>
    <pre>
    	枚举x,拆绝对值,得
    	①:x-y <=k    -> x-k <= y
    	②:y-x <=k     -> y <= x + k
    	-> x-k <= y <= x + k
    	由于两个数组有序,随着x得增大,y必然增大,可用双指针解决
    </pre>
</details>
