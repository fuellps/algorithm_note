### 定长滑动窗口

> 这类题目一般是求每一个子串/子数组在长度为k的情况下,某些与统计有关的问题

$暴力的做法:枚举子数组右端点i,再枚举左端点不断扩大直到i-k+1,统计区间内相关的值$

$时间复杂度O(n*k)$



> 对于某些题目,我们可以先形成长度为k的窗口,在枚举子数组右端点i**入窗口**时更新,统计答案  . 当i == k -1时,窗口左端点 i - k + 1**出窗口**,更新窗口内相关性质



对于数组长度为n,长度为定长k$(1 <= k <= n)$的窗口,窗口的个数为**n-k+1**.

> 可以这样理解.从第k个数开始能够形成1个长度为k的子数组.所以在[k:n]区间内都能形成一个子数组.共n - k + 1个长度为k的子数组.

对于大部分题目都可以用一个for循环解决.**注意窗口大小为0的话需要特判**

```c++
//示例:求长度为k的子数组最大和
int s = 0;
int ans = 0; //
for(int i = 0; i  < nums.size(); i ++){
    s += nums[i];
    if(i < k - 1) continue; //还不能形成窗口
    ans = max(ans,s);
     s -= nums[i-k + 1]; //同时去掉无用元素
}
return ans;
```



**但是当题目窗口大小可能为0的话推荐用两个for循环写法,更加通用**.第一个循环先形成第一个窗口,然后统计特定的要求.再处理剩下的窗口.

```c++
//示例:求长度为k的子数组最大和
int s = 0;
for(int i =0;i < k; i++){//形成[0,k-1]长度为k的窗口
    s += nums[i]; 
}
int ans = s; //记录第一个窗口的答案
for(int i = k; i  < nums.size(); i ++){
    s += nums[i] - nums[i-k]; //移动窗口.同时去掉无用元素
    ans = max(ans,s);
}
return ans;
```
