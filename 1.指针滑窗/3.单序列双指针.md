### 1.相向双指针

> 对于索引i及其关于中心对称位置,满足i+j = n - 1,因此j = n - i - 1

也可以理解为第i个元素的对称位置应满足:

从头部到i的距离 = 从尾部到j的距离.

#### 套路1:解决a+b `<` ,`=`,`>` c之类的问题: &#x1F60D;&#x1F60D;&#x1F60D;&#x1F60D;

> 由于排序后两数之和的范围已经确定,
> $$
> \begin{aligned}
> &若a+b<c,则a+(b-1),a+(b-2),\dots,a+(b-a+1)都<c \\
> &若a + b > c,则 (a+1)+b,(a+2)+b,\dots,(a+b-1)+b都>c
> \end{aligned}
> $$

利用数组**有序**的性质,根据a + b的情况移动左右指针.

```java
public countPairs(int[] nums,int target){
    //求a + b < target的二元组数量
    Arrays.sort(nums);
    int l = 0, r=  nums.length - 1,ans = 0;
    while(l < r){ // [l,r) < target
        int s = nums[l] + nums[r];
        if(s < target){
            ans+= r- l; 
            l++;
        }else{ // [l,r) >= target
            r--;
        }
    }
    return ans;
}
```
