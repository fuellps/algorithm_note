#### 套路1:解决a+b `<` ,`=`,`>` c之类的问题:

> 由于排序后两数之和的范围已经确定,因此可以通过比较进行移动.

利用数组**有序**的性质,根据a + b的情况移动左右指针.

```java
//求a + b < target的二元组数量
Arrays.sort(nums);
int l = 0, r=  nums.length - 1;
while(l < r){
    int s = nums[l] + nums[r];
    if(s < target){
        ans+= r- l; //nums[l,r],nums[l+1,r],nums[l+2,r]...nums[r-1,r]即在[l,r)范围的l下标都能满足,有r-l个.
        l--;
    }else{
        r++;
    }
}

```
