## 二分查找

### 基础查找

1. **lower_bound**:找到大于等于x的第一个数,找不到返回len(nums)

```java
//Java
int lower_bound(int[] nums,int l,int r,int x){
    int l = -1, r = nums.length;
    while (l + 1 < r){
        int mid = l + r >> 1 // l + (r - l)/2 
        if(nums[mid] < x){
            l = mid;
        }else{
            r = mid;
        }
    }
    return r;
}
```

```python
#Python
from bitsect import bisect_left
return bisect_left(x)
```



```c++
//C++
return lower_bound(nums.begin(),nums.end(),x) - nums.begin()
```

2. **upper_bound**:找到大于x的第一个数，找不到返回数组长度

```java
//Java
int lower_bound(int[] nums,int l,int r,int x){
    int l = -1, r = nums.length;
    while (l + 1 < r){
        int mid = l + r >> 1 // l + (r - l)/2 
        if(nums[mid] <= x){ //这里改变了
            l = mid;
        }else{
            r = mid;
        }
    }
    return r;
}
```

```python
return bisect_right(x)
```



```c++

return upper_bound(nums.begin(),nums.end(),x) - nums.begin()
```

### 找到最左边且最接近x的k个数

```c++
vector<int> findKClosed(vector<int> &nums,int x,int k){
    int l = -1,r = nums.size() - k; //确定二分的区间左边界范围
    while(l+1 < r){
        int mid = l + r >> 1;
        if(nums[mid+k] - k < nums[mid]){
            l = mid;
        }else{
            r = mid;
        }
    }
    //二分结束，此时r为最接近x的k个数的左边界
    vector<int> res;
    for(int i = r;i < r + k; i++){
        res.push_back(nums[i]);
    }
    return res;
}
```
