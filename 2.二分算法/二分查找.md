
### 基础查找
1.找到大于等于x的第一个数,找不到返回len(nums)

```java
int lower_bound(int[] nums,int l,int r,int x){
    int l = -1, r = nums.length;
    while (l + 1 < r){
        int mid = l + r >> 1 // l + (r - l)/2 
        if(nums[mid] < x){
            l = mid;
        }else{
            r = mid;
        }
    }
    return r;
}
```

```python
from bitsect import bisect_left
return bisect_left(x)
```

```c++
return lower_bound(nums.begin(),nums.end(),x) - nums.begin()
```
