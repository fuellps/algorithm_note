### 递推法求组合数

$公式:\dbinom{n}{k} = \dbinom{n-1}{k-1} + \dbinom{n-1}{k}$

解释:从n个人中选k个人的方案数等价于选第k个人,然后从n-1个人中再选择k-1个人;

或者不选第k个人,从n-1个人中选k个数.

```python
def calcomb(n,m):
    comb = [[for _ in range(m+1)] for _ in range(n+1)]
    for i in range(0n+1):
        for j in range(i+1):
            if j == 0:
                comb[i][j] = 1
            else:
                comb[i][j] = comb[i-1][j-1] + comb[i-1][j]
```
