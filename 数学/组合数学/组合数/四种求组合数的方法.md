### 递推法求组合数

$公式:\dbinom{n}{k} = \dbinom{n-1}{k-1} + \dbinom{n-1}{k}$

解释:从n个人中选k个人的方案数等价于选第k个人,然后从n-1个人中再选择k-1个人;

或者不选第k个人,从n-1个人中选k个数.

```c++
void initcomb(int n,int mod):
     comb[0][0] = 1; 
    for(int i  =1;i < n; i++){
        comb[i][0] = 1;
        for(int j = 1;j <= i; j++){
            comb[i][j] = (comb[i-1][j-1] + comb[i-1][j])%mod;
        }
    }
```

$适用于a,b \le 5000$

### 从定义出发

$\dbinom{n}{k} =\dfrac{n!}{k!(n-k)!}$

可以预处理$阶乘及其逆元。$

$显然有inv[i+1] = \dfrac{1}{(i+1)!},则inv[i] = inv[i+1]*(i+1)$

```c++
ll inv[N];
ll fact[N];
int mod = 1e9 + 7;
void init(){
    fact[0] = 1;
    for(int i = 1;i <= n; i++){
        fact[i] = fact[i-1]*i%mod;
    }
    inv[n] = qpow(fact[n],p-2,p);
    for(int i  = n - 1;i >= 0;i--){
        inv[i] = inv[i+1]*(i+1);
    }
}
ll C(int a,int b){
    if(a > b) return 0;
    return fact[a]*inv[b]%mod*inv[a-b]%mod;
}
```

适用于 $a,b \le 100000$

### 利用卢卡斯定理解决大数组合数

见 [卢卡斯定理](..\..\数论\卢卡斯定理.md)

```c++
int lucas(ll a,ll b){
    if(!b) return 1;
    return C(a%p,b%p)*lucas(a/p,b/p)%p;
}
```

适用于 $a,b\le1e18, p为质数且<=1e5$

### 分解质因数

解决求组合数,且$无模数$的问题.

$分别分解n!,k!,(n-k)!质因数的个数，\\则组合数p_i的个数为get(n!,p_i)-get(b!,p_i)-*get((n-k)!,p_i)$

根据唯一分解定理 $a=p_1^{\alpha_1}*\dots*p_n^{\alpha^n}$计算答案。

```c++
#include <bits/stdc++.h>
using namespace std;
const int N = 5e3 + 10;
int pri[N],cnt;
bool st[N];
void get_prime(int n){
    for(int i = 2;i  <= n; i++){
        if(!st[i]){
            pri[cnt++] = i;
        }
        for(int j = 0; pri[j] <= n/i; j++){
            st[pri[j]*i] = true;
            if(i%pri[j] == 0) break;
        }
    }
}
//求n!中含质因数p的个数
int get_prime_factor(int n,int p){
    int res = 0;
    while(n){
        res += n/p;
        n/=p;
    }
    return res;
}
vector<int> mul(vector<int> &a,int b){
    vector<int> c;
    int t = 0;
    for(int i  = 0;i < a.size();i++){
        t += a[i]*b;
        c.push_back(t%10);
        t/=10;
    }
    while(t){
        c.push_back(t%10);
        t/=10;
    }
    return c;
}
int main(){
    int a,b; cin >> a >> b;
    get_prime(a);
    vector<int> ans{1};
    for(int i = 0;i < cnt; i++){
        int res = get_prime_factor(a,pri[i]) - get_prime_factor(b,pri[i]) - get_prime_factor(a-b,pri[i]);
        for(int j = 0;j < res;j++)
        ans = mul(ans,pri[i]);
    }
    for(int i = ans.size() - 1; i >= 0; i--){
        printf("%d",ans[i]);
    }
    printf("\n");
}
```

def comb(n,m):
