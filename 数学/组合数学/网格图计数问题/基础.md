在n行m列的网格图中,每次只能向下或者向右走.从左上角(0,0),到达右下角(n-1,m-1)的方案数:

可以这样想:从(0,0)到达(n-1,m-1)需要向右走m-1步,向下走n-1步.在所有的组合方案中选向m-1步或者n-1步即为答案.



如果要求在最下面a行,最左边b列的交叉位置下面的地方都不能访问的话,可以将原来的网格图分割为两个矩形,按照x轴或者y轴进行划分.



$C^m_n = \frac{n!}{(n-m)!m!}$代码实现时先预处理阶乘和逆元.

```c++
typedef long long ll;
ll fact[N];
ll inv[N];
int main(){
    fact[0] = 1;
    for(int i = 1; i < N; i++){
        fact[i] = fact[i-1]*i%mod;
    }
    inv[N-1] = qpow(fact[N-1],mod - 2); //费马小定理
    for(int i = N - 2; i >= 1; i--){
        inv[i] = inv[i+1]*(i+1)%mod; //线性递推求阶乘逆元
    }
    ll ans = 0;
    for(int  j = b;j < m; j++){
        //枚举x轴作为
        ans = (ans + C(0,0,n -a - 1,j)*C(n-a,j,n-1,m-1))%mod;
    }
    return 0;
}
//从(x1,y1)到达(x2,y2)的方案数
int getC(int x1,int y1,int x2,int y2){
    return C(x2 - x1 + y2 - y1)*C(x2 - x1);
}
//求组合数C
int C(int n,int m){
    if(n == m || m == 0) return 1;
    return fact[n] * inv[n-m]%mod*inv[m]%mod;
}
```
