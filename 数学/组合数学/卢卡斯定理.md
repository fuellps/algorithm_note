### 引入

Lucas 定理用于求解大组合数取模的问题，其中模数必须为素数。正常的组合数运算可以通过递推公式求解（见[组合数](../组合数学/组合数/四种求组合数的方法)），但当问题规模很大，而模数是一个不大的质数的时候，就不能简单地通过递推求解来得到答案，需要用到 Lucas 定理。

### 定义

Lucas定理内容如下：对于质数 **p**,有：

  $\dbinom{n}{k}= \dbinom{\lfloor \dfrac{n}{p} \rfloor}{\lfloor \dfrac{k}{p} \rfloor}* \dbinom{n \mod p}{k \mod p} \mod p$

观察上述表达式，可知$n \mod p$ 和 $k \mod p$  一定是小于$p$的数，可以直接求解，$\dbinom{\lfloor \dfrac{n}{p} \rfloor}{\lfloor \dfrac{k}{p} \rfloor}$ 可以继续用 Lucas 定理求解。这也就要求 $p$ 的范围不能够太大，一般在 $1e5$ 左右。边界条件：当 $k=0$ 的时候，返回 1。

> 时间复杂度为:
>
>  $O(f(p) + g(p) \log_p n),\\其中 f(n)为预处理组合数的复杂度， g(n)为单次求组合数的复杂度。$



### 证明

$$
引理1:当p为质数时， \dbinom{p}{x} \equiv 0 \pmod p,其中0 \lt x \lt p \\
\dbinom{p}{x}\equiv \dfrac{p!}{x!(p-x)!} = \dfrac{p}{x}*\dfrac{(p-1)!}{(x-1)!(p-x)!}
\equiv p*inv(x)*\dbinom{p-1}{x-1} \equiv 0 \pmod p\\
$$


$$
引理2:当p为质数时， (1+x)^p \equiv 1 + x^p \pmod p \\
由二项式定理可得:(1+x)^p = \sum_{i=0}^{p}\dbinom{i}{p}x^i,由引理1可得\sum_{i=1}^{p-1}\dbinom{i}{p} \equiv 0 \pmod p \\
因此((1+x)^p \equiv 1 + x^p \pmod p
$$

$$
假设n \gt p,m \gt p,则令n=ap+b,m=cp + d \\
(1+x)^n = \sum_{i=0}^{n}\dbinom{n}{i}x^i &(1)\\ 
(1+x)^n = (1+x)^{ap+b}=((1+x)^p)^{a}*(1+x)^b\\
=(1+x^p)^a *(1+x)^b \equiv \sum_{i=0}^{a}\dbinom{a}{i}x^{ip}*\sum_{i=0}^{b}\dbinom{b}{i}x^i \pmod p  &(2)\\
由(1)可得x^m的系数为\dbinom{n}{m},\\
因为x^m=x^{cp+d}，因此x^m的系数为\dbinom{a}{c}\dbinom{b}{d}\\
即\dbinom{n}{m}  \equiv\dbinom{a}{c}\dbinom{b}{d} \pmod p
$$


```c++
long long Lucas(long long n, long long k long long p) {
  if (k == 0) return 1;
  return (C(n % p, k % p, p) * Lucas(n / p, k / p, p)) % p;
}
```

> 适用范围$a,b \le 1e18,\quad p \le1e5$

由于p是质数,根据Wilson定理可得: $(p-1)! \equiv -1$,可以如下预处理逆元及阶乘.
