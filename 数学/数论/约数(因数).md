### 分解质因数

对于一个正整数x,最多有1个质因数大于$\sqrt x$.

> 反证法:假使x存在两个数质因数p1,p2大于$\sqrt x$,那么p1*p2 > x.不符合唯一分解定理.

因此可以枚举2~$\sqrt x$中x的质因数,并不断去掉该质因数.

```c++
unordered_map<int,int> result;
void breakdown(int x){
    for(int i = 2; i <= x/i; i++){
        while(x%i==0){
            result[i] += 1;
            x/=i;
        }
    }
    if(x>1) result[x] += 1;
}
```

> 时间复杂度:$O(\sqrt x)$,最好的情况下可以达到$O(\log n)$

###### 还可以预处理每个数的LPF(x),最小质因子,做到 $O(log n)$分解.

### 试除法求约数

①:暴力做法:枚举1~x中的所有数,判断是否能够整除x.

②:枚举1~$\sqrt n$的数即可.若$d|x,则\frac{x}{d}|x$.

```c++
vector<int> factor(int x){
    vector<int> result;
    for(int i = 1;i <= x/i; i++){
        if(x%i==0){
            result.push_back(i);
            if(i != x/i) result.push_back(x/i);
        }
    }
    return result;
}
```

> 时间复杂度 $O(\sqrt n)$

### 求约数个数

#### 约数个数定理

> 若n=$\prod_{i=1}^{m}p_i^{c_i}$,则$d_i=\prod_{i=1}^{m}(c_i + 1)$
>
> 证明:因为$p_i^{c_i}$的约数个数有$c+1$个,根据乘法原理可知n的约数个数为$\prod_{i=1}^{m}(c_i + 1)$

```c++
void countFactor(int x){
    unordered_map<int,int> pri;
	for(int i = 2; i <= x/i;i++){
        if(x%i == 0){
            pri[x] += 1;
        }
    }
    if(x > 1) pri[x] += 1;
    ans = 1;
    for(auto entry : pri){
        ans *= entry.second;
    }
    cout << "约数个数为: "<< ans << endl;
}
```

> 时间复杂度:$O(\sqrt n)$

### 求约数之和

> 约数和定理：
>
> :$s=(p_1^0+p_1^1 + \dots +p_1^{c_1})*(p_2^0+p_2^1 \dots + p_2^{c_2})*(p_n^0+p_n^1 + \dots +p_n^{c_n})$

```c++
void countFactor(int x){
```
