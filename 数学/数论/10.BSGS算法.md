### BSGS算法(Baby Step,Giant Step)

用于求解高次同余方程，其中a与p互质。

> $$
> &给定a,b,p,其中a与p互质 \\
> &求解 a^x \equiv b \pmod p的最小非负整数x.
> $$

$$
由扩展欧拉定理可知: a^x \equiv a^{x \mod \phi(p)} \\
由于 \phi(p) < p,因此x不超过p.但暴力枚举的话时间复杂度为 O(p),如何优化呢? \\
若b=1，则显然x最小取0.直接返回即可。\\
利用分块思想进行优化 \\
令x = im-j,其中m=\lceil \sqrt p\ \rceil,i \in [1,m],j \in[0,m-1]。则有x \in [1,p]\\
则有a^{im-j} \equiv b \pmod p \\
由于a^j与p互质，因此乘法逆元一定存在，两边同时乘以a^j得\\
(a^m)^i \equiv b*a^j \pmod p \\
可以用哈希表先预处理b*a^{j}的值，然后枚举i，判断是否满足条件即可。
$$

```c++
int bsgs(ll a,ll b,ll p){
    a%=p;b%=p;
    if(b == 1) return 0; //特判
    unordered_map<int,int> mp;
    int m = ceil(sqrt(p));
    mp[b] = 0;
    ll t = b;
    for(int j = 1;j < m; j++){
        t = t*a%p;
        mp[t] = j;
    }
    ll mi = 1;
    for(int i = 1;i <= m; i++) mi=mi*a%p;
    t = 1;
    for(int i = 1;i <= m; i++){
        t = t*mi%p;
        if(mp.find(t) != mp.end()) return i*m-mp[t];
    }
    return -1;
}
```

> 时间复杂度 $O(\sqrt q)$

### 扩展BSGS算法

用于求解高次同余方程，其中a,p不一定互质。

> $给定a,b,p,求解 a^x \equiv b \pmod p的最小非负整数x.$

$$
因为a与p不一定互质，所以应让使其互质然后使用BSGS算法 \\
令d = gcd(a,p) \\
原方程等价于a*a^{x-1} + py = b \\
若 d \not{\vert}\ b,则方程无解。\\
否则方程都除以d，则为\frac{a}{d}*a^{x-1} + \frac{p}{d}y = \frac{b}{d} \\
等价于 \frac{a}{d}*a^{x-1}  \equiv \frac{b}{d} \pmod {\frac{p}{d}} \\
一直持续下去，直到a'与p'互质或者无解\\
假设执行到最后，方程变为 \frac{a^k}{d_1 \dots d_k}*a^{x-k}  \equiv \frac{b}{_1 \dots d_k} \pmod {\frac{p}{_1 \dots d_k}} \\
则原问题等价于求a^{x-k} \equiv  \frac{b}{_1 \dots d_k} \pmod {\frac{p}{_1 \dots d_k}} 的最小非负整数解+k，可以用BSGS算法解决。
$$

```c++
int gcd(int a,int b){ return b == 0 ? a : gcd(b,a%b);}
int exbsgs(int a,int b,int p){
    if(b == 1 || p == 1) return 0; //一定满足
    int A = 1,k=0;
    while(true){
        int d = gcd(a,p); 
        if(b%d) return -1; //裴蜀定理
        b/=d;p/=d;
        A*=a/d;
        k++;
        if(A == b) return k;
    }
    unordered_map<int,int> mp;
    mp[b] = 0;
    int m   ceil(sqrt(m));
    ll t = 1;
    for(int j = 1;j < m; j++){
        t = t*a%p;//b*a^j
        mp[t] = j;
    }
    ll mi = 1;
    for(int i = 1;i <= m; i++) mi*=a; //a^m
    t = A;
    for(int i = 1;i <= m; i++){
        t = t*mi%p;//A(a^m)^i
        if(mp.find(t) != mp.end()) return i*m-mp[t] + k;
    }
    return -1;
}
```
