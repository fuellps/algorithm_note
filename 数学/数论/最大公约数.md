## 模板

### 欧几里得算法

>  不引起歧义的情况下,(a,b)表示gcd(a,b)

核心:$当b \ne 0时,(a,b) = (b,a \mod b)$

$当b = 0时,gcd(a,0) = a$

> 证明:①设d = (a,b),则 d | a,d | b. $a \mod b\ =\ a\ - \lfloor \frac{a}{b} \rfloor*b = a-c*b$
>
> $\Longrightarrow$ b | $ a \mod b$
>
> 因此d|$(b,a \mod b)$.
>
> ②:若d=$(b,a \mod b)$,则d | b,d | a - c*b $\Longrightarrow$ d | a.
>
> 因此 d | (a,b)

```c++
int gcd(int a,int b){
    return b ? gcd(a,b) : a;
}
```

> 时间复杂度 $O(\log\ max(a,b))$

#### 多个数的最大公约数

按照两个数的方式一一求解即可.

#### 最小公倍数

对于两个数a,b,将其分解为标准素因数分解式,可得

> (a,b) = $p_1^{min(k_{a_1},k_{b_1})}* \dots *p_n^{min(k_{a_n},k_{b_n})}$
>
> [a,b] = $p_1^{max(k_{a_1},k_{b_1})}* \dots *p_n^{max(k_{a_n},k_{b_n})}$
>
> 由于 $k_{a_i}+k_{b_i} = max(k_{a_1},k_{b_1}) + min(k_{a_1},k_{b_1})$
>
> 因此: $[a,b] = \dfrac{a*b}{(a,b)}$

```c++
ll lcm(int a,int b){
    return a/gcd(a,b)*b;
}
```

> 时间复杂度 $O(\log\ max(a,b))$

### 扩展欧几里得算法

用于求解 $ax+by=gcd(a,b)$的一组可行性解。

由欧几里得定理可知:$(a,b)=(b,a\mod b)$

> 算法流程：
>
> 递归终止时，b=0,则有x=1,y=0.
>
> 递归回溯时，已知 $x'$,$y'$的值，由于:$(a,b)=(b,a\mod b)$，则
> $$
> \begin{aligned}
> ax+by&=\ bx'+(a - \lfloor \frac{a}{b} \rfloor*b)y'\\
> &=\ bx' + ay' - \lfloor \frac{a}{b} \rfloor b*y'\\
> &=ay'+b(x'-\lfloor \frac{a}{b} \rfloor y') 
> \end{aligned}
> $$
>
> 因此x=$y$',y=$x'-\lfloor \frac{a}{b} \rfloor y' $ 

一个结论：若$b \ne 0,扩展欧几里得算法求出的可行解必有 \abs{x} \le b,\abs{y} \le a$

```c++
int x,y;
int exgcd(int a,int b){
    if(!b){
        x = 1,y = 0;
        return a;
    }
    int res = exgcd(b,a%b);
    int t = x;
    x = y;
    y = t - a/b*y;
    return res;
}
```

> 时间复杂度 $O(\log\ max(a,b))$
