### 欧几里得算法

>  不引起歧义的情况下,(a,b)表示gcd(a,b)

核心:$当b \ne 0时,(a,b) = (b,a \mod b)$

$当b = 0时,gcd(a,0) = a$

> 证明:①对于(a,b)是 $b,a \mod b$的公约数。
>
> 设d = (a,b),则 d | a,d | b. $a \mod b\ =\ a\ - \lfloor \frac{a}{b} \rfloor*b = a-c*b$
>
> $\Longrightarrow$  $d \mid (a \mod b)$ 
>
> ②:反过需证 若d=$(b,a \mod b)$，则 d | a,d | (a,b)
>
> 因为d | b,d | a - c*b $\Longrightarrow$ d | a. 
>
> 因此 d | (a,b)

```c++
int gcd(int a,int b){
    return b ? gcd(a,b) : a;
}
```

> 时间复杂度 $O(\log\ max(a,b))$
>
> 对a取模会让**a至少减半**，这样最多发生log次。

#### 最小公倍数

对于两个数a,b,将其分解为标准素因数分解式,可得

> (a,b) = $p_1^{min(k_{a_1},k_{b_1})}* \dots *p_n^{min(k_{a_n},k_{b_n})}$
>
> [a,b] = $p_1^{max(k_{a_1},k_{b_1})}* \dots *p_n^{max(k_{a_n},k_{b_n})}$
>
> 由于 $k_{a_i}+k_{b_i} = max(k_{a_1},k_{b_1}) + min(k_{a_1},k_{b_1})$
>
> 所以 $a*b = [a,b]*(a,b)$
>
> 因此: $[a,b] = \dfrac{a*b}{(a,b)}$

```c++
ll lcm(int a,int b){
    return a/gcd(a,b)*b;
}
```

> 时间复杂度 $O(\log\ max(a,b))$

#### 性质

- $gcd(a,b) \le min(a,b)$

### 裴蜀定理

$$
设a,b为不全为0的整数，则存在整数x,y满足ax+by=gcd(a,b)
$$

推论：
$$
若a和b是不全为0的整数，a,b互质，则ax+by=1 \\
若a和b是不全为0的整数,ax+by=c有解，则c一定为gcd(a,b)的倍数
$$


### 扩展欧几里得算法

用于求解 $ax+by=gcd(a,b)$的一组可行性解。

由欧几里得定理可知:$(a,b)=(b,a\mod b)$

> 算法流程：
>
> 递归终止时，b=0,则有x=1,y=0.
>
> 递归回溯时，已知 $x'$,$y'$的值，由于:$(a,b)=(b,a\mod b)$，则
> $$
> \begin{aligned}
> ax+by&=\ bx'+(a - \lfloor \frac{a}{b} \rfloor*b)y'\\
> &=\ bx' + ay' - \lfloor \frac{a}{b} \rfloor b*y'\\
> &=ay'+b(x'-\lfloor \frac{a}{b} \rfloor y') 
> \end{aligned}
> $$
>
> 因此x=$y$',y=$x'-\lfloor \frac{a}{b} \rfloor y' $ 

**一个结论**：若$b \ne 0,扩展欧几里得算法求出的可行解必有 \abs{x} \le b,\abs{y} \le a$

```c++
int x,y;
int exgcd(int a,int b){
    if(!b){
        x = 1,y = 0;
        return a;
    }
    int res = exgcd(b,a%b);
    int t = x;
    x = y;
    y = t - a/b*y;
    return res;
}
```

> 时间复杂度 $O(\log\ max(a,b))$

##### 二元一次方程通解

$$
若ax+by=d,其中d为gcd(a,b).\\
若x_0,y_0为一个特解\\
则有

\begin{cases}
x = x_0 + \frac b d\,k,\\[1ex]
y = y_0 - \frac a d\,k,
\end{cases}\quad k\in\mathbb Z
$$

> 证明如下:
> $$
> \begin{aligned}
> &已知ax_0+my_0 = b,ax+my=b.\\
> &则a(x-x_0)+=m(y-y_0)\\
> &两边同时除以gcd(a,b)得\frac{a(x-x_0)}{gcd(a,m)}=\frac{m(y_0-y)}{gcd(a,m)}.\\
> &由于(\frac{a}{gcd(a,m)},\frac{m}{gcd(a,m)}) = 1,\\
> &因此(x-x_0)一定是\frac{m}{gcd(a,m)}的倍数,\\
> &则x-x_0=\frac{m}{gcd(a,m)}*k\\
> &\therefore x=x_0 + \frac{m}{gcd(a,m)}*k \\
> &同理可证y = y_0 - \frac{a}{gcd(a,m)}*k
> \end{aligned}
> $$
>
> 

$$
若ax+by=c,设d为gcd(a,b)则c为d的倍数.\\
可以解得x_0,y_0为ax+by=d的一个特解\\
则x_0' = c/d*x_0,y_0'=c/d*y_0 \\
则有
\begin{cases}
x = x_0' + \frac b d\,k,\\[1ex]
y = y_0' - \frac a d\,k,
\end{cases}\quad k\in\mathbb Z
$$

证明过程可参考上面。

> 扩展:若ax+by=c,设d为gcd(a,b)则c为d的倍数\\
> 	求x,y都为正整数的解数量,x的最小/大正整数解，y的最小/大正整数解.\\
> 	如果不存在，则求x得最小正整数解，y得最小正整数解.\\

$$
记tx=b/d,ty=a/d\\
\begin{aligned}
&若x>0,则有x_0'+tx*k>0,\therefore k >  -x_0'/tx  \\
&若y>0,则有y_0'-ty*k>0,\therefore k<  y_0'/ty  \\
\end{aligned}\\
因为x,y都要>0,且k为整数，所以 \lceil \dfrac{-x_0'+1}{tx} \rceil \le k \le \lfloor \dfrac{-y_0'-1}{ty }\rfloor \\
所以当\lceil \dfrac{-x_0'+1}{tx} \rceil \gt \lfloor \dfrac{-y_0'-1}{ty }\rfloor,无正整数对解。\\
否则①当k=\lceil \dfrac{-x_0'+1}{tx} \rceil,x取得最小正整数解，y取得最大正整数解. \\
②当k= \lfloor \dfrac{-y_0'-1}{ty}\rfloor,x取得最大正整数解，y取得最小正整数解. \\
$$

> x的最小正整数解也可用(x0%tx+tx)%tx表示
>
> y的最小正整数解也可用(y0%ty+ty)%ty表示
