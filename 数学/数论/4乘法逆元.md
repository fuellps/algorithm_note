### 费马小定理

$$
若p为质数，则有 a^p \equiv a \pmod p \\
若 gcd(a,p)=1,则有 a^{p-1} \equiv 1 \pmod p
$$



## 定义

> 对于1个数a,若a与m互质,则存在一个整数b,使得: $a*b \equiv 1 \pmod m  \tag 1$
>
> 此时，称b为a在模m下的乘法逆元，记作 $a^{-1}$.

##### 乘法逆元存在条件

a的乘法逆元存在的条件是a与模数m互质。

## 模板

### 快速幂求逆元

求a在模p下的逆元。（其中p为质数）

$$
\begin{aligned}
&由于p为质数，由费马小定理可知 a^{p-1} \equiv 1 \pmod p \quad式1\\
&①：若a为p的倍数，则无解。\\

&②：若a不为p的倍数，则求一个数x满足a*x \equiv 1 \pmod p \quad式2\\
&由式1，式2可得x \equiv a^{p-2} \pmod p
\end{aligned}
$$
快速幂见 [快速幂](快速幂)

```c++
//快速幂求逆元
#include <bits/stdc++.h>
using namespace std;

typedef long long ll;
int qpow(ll a,int b,int p){
    ll res = 1;
    for(;b;b>>=1){
        if(b&1) res = res*a%p;
        a=a*a%p;
    }
    return res;
}
int main(){
    int n,a,p;
    cin >> n;
    while (n -- ){
        cin >> a>>p;
        //p是质数,当且仅当a是p的倍数时a和p不互质.
        //因此如果a是p的倍数说明a与p不互质,不存在逆元
        if(a%p == 0) cout <<"impossible" <<endl;
        else cout << qpow(a,p-2,p) << endl;
    }
}

```

### 扩展欧几里得算法求逆元

当p不是质数时,可以用扩展欧几里得算法求逆元.

1.引理:$婓蜀定理:一定存在整数x,y,满足ax+by =gcd(a,b)$

2.要求   $a * x \equiv 1 \pmod m$ ,可转化$a*x + m*y = gcd(a,m)$,其中gcd(a,m)=1

扩展欧几里得算法见见[扩展欧几里得算法](最大公约数###)


```c++
#include <bits/stdc++.h>
using namespace std;

int x,y;
int exgcd(int a,int b){
    if(!b){
        x = 1,y = 0;
        return a;
    }
    int res = exgcd(b,a%b);
    int t = x;
    x = y;
    y = t - a/b*y;
    return res;
}

int main()
{
    int n;cin >> n;
    while (n -- ){
        int a,m;cin >> a>>m;
        int gcd = exgcd(a,m);
        if(gcd != 1) cout <<"impossible" << endl;
        else cout << ((long long)x +m)%m<< endl;//abs(x) <= p
    }
}
```

### 线性求1~N之间的逆元

$题意:求出1-N中与在质数p模意义下的逆元，其中N \lt p$

首先有$1^{-1}*1 \equiv 1 \mod p$,

> 证明：$对于任意\forall p \in \Zeta,满足1*1 \equiv 1 \pmod p,所以1的逆元是1$

那么对于$i^{-1}$的情况,假设 $k = \lfloor p/i \rfloor$,那么有$p = k*i + j$,其中$j = p\%i$.

**在模p意义下有：**

$k*i+j \equiv 0,其中(0 < j < p)$ 

因此在上述方程两边同时乘上$i^{-1}*j^{-1}$,得到$kj^{-1} + i^{-1} \equiv 0$

则$i^{-1} \equiv -k*j^{-1}$

即$i^{-1} \equiv -\lfloor p/i \rfloor * (p\mod i)^{-1} \equiv (p-\lfloor p/i \rfloor)*(p \mod i)^{-1}$

注意到: $p\mod i < i$,因此再求出i之间已经求出p%i的逆元,因此可以线性递推.

```c++
int inv[N];
inv[1] = 1;
for(int i = 2; i <= n; i++){
    inv[i] = (long long)(p - p/i)*inv[p%i]%p.//在里面加上p,防止出现负数
}
```

### 线性求阶乘逆元

对于阶乘有这个关系: ${n!}*\frac{1}{n!} = 1$

因此$inv[i+1] = \frac{1}{(i+1)!} \Longrightarrow inv[i]=inv[i+1]*(i+1),$

所以可以先求出n!的逆元，然后从后往前递推，就可以求出1...n!的所有逆元.

```c++
long long fact[N],inv[N];
void init_factorinv(){
    //假使模数为质数p
    fact[0] = 1;
    for(int i = 1; i < N; i++) fact[i] = fact[i-1]*i%p;
    inv[n] = qpow(mul,p-2,p);
    for(int i = N - 1; i >= 0 ; i--){
        inv[i] = inv[i+1]*fact[i+1];
    }
}
ll c(int a, int b){
    return a < 0 || a < b ? 0 : fact[a]*inv[b]%mod*inv[a-b]%mod;
}
```

### 线性求任意n个数的逆元

要求任意给定 𝑛 个数$(1≤𝑎_𝑖<𝑝)$的逆元,需要用到下面的方法:

首先计算$a_i$前n项的前缀积,记为$S_i$.然后用快速幂或扩展欧几里得算法求出$S_n的逆元记为Sv_n$。

我们可以求出所有$Sv_i$，这样$a_i^{-1} \equiv Sv_n*S_{n-1} \pmod m$

对于$Sv_{i}可以通过Sv_{i+1}*a[i+1]$求得。

因此,只要求出$\frac{1}{S_i}$,再乘上前n-1个数的积即可求出$a_i$的逆元。

而$\frac{1}{S_i}$可以先求出$\frac{1}{S_n}$,从后往前递推求出。

```c++
typedef long long ll;
int a[N]; //存放要求的数字的逆元
int s[N]; //存放前n个数的乘积
ll sv[N]; //存放1/Si的结果.
int a,,n,p;
void init(){
    //初始化...
    s[0] = 1;
    for(int i = 1;i <= n; i++){
        s[i] = (ll)s[i-1]*a[i]%p;
    }
    sv[n] = qpow(s[n], p - 2); //假设p是质数
    for(int i =  n - 1; i  >= 1; i--){
        sv[i] = sv[i+1]*a[i+1]; //求1/S_{i-1} = S{i+1}*a[i]
    }
    for(int i = 1; i <= n; i++){
        cout << sv[i]*s[i-1] << " ";//1/{a_i} = 1/Sn*s[n] 
    }
}
```
