### 试除法判断是否为质数

> 题意:给定一个数x,判断是否为质数.

①:暴力做法:枚举2~x-1,判断是否能整数x,如果都不能整除x,那么就是质数.

②:只需枚举$2 \sim \sqrt{x}$即可.因为如果$a|x,那么\frac{x}{a}|x$

```c++
bool is_prime(int x){
    if(x <= 1) return false;
    for(int i = 2; i <= x/i; i++){
        if(x%i==0) return false;
    }
    return true;
}
```

> 时间复杂度:$O(\sqrt{n})$



### 分解质因数

对于一个正整数x,最多有1个质因数大于$\sqrt x$.

> 反证法:假使x存在两个数质因数p1,p2大于$\sqrt x$,那么p1*p2 > x.不符合唯一分解定理.

因此可以枚举2~$\sqrt x$中x的质因数,并不断去掉该质因数.

```c++
unordered_map<int,int> result;
void breakdown(int x){
    for(int i = 2; i <= x/i; i++){
        while(x%i==0){
            result[i] += 1;
            x/=i;
        }
    }
    if(x>1) result[x] += 1;
}
```

> 时间复杂度:$O(\sqrt x)$,最好的情况下可以达到$O(\log n)$



### 素数筛

> 求1~n中的素数.

#### 埃氏筛

枚举2~$\sqrt n$,如果当前数是没被筛过,就以当前数的倍数去筛掉合数.

```c++
int primes[N];
bool not_prime[N];
int cnt;
void count_prime(int n){
    for(int i = 2; i <= n/i; i++){
        if(! not_prime[i]){
            primes[cnt++] = i;
            if((long long)i*i > n) continue; 
            for(int j = i*i; j <= n; j += i){
                primes[j] = true;
            }
        }
    }
}
```

>  时间复杂度$O(n\log\log n)$

#### 线性筛(欧拉筛)

保证每一个合数只被该合数的最小质因数筛掉.

```c++
int primes[N];
bool not_prime[N];
int cnt;
void count_prime(int n){
    for(int i = 2; i <= n/i; i++){
        if(! not_prime[i]){
            primes[cnt++] = i;
        }
        for(int j = 0; primes[j] <= n/i;j++){
            not_prime[primes[j]*i] = true;
            if(i%primes[j] == 0) break;
        }
    }
}
```

> 时间复杂度:$O(n)$
