### 试除法判断是否为质数

> 题意:给定一个数x,判断是否为质数.

①:暴力做法:枚举2~x-1,判断是否能整数x,如果都不能整除x,那么就是质数.

②:只需枚举$2 \sim \sqrt{x}$即可.因为如果$a|x,那么\frac{x}{a}|x$

```c++
bool is_prime(int x){
    if(x <= 1) return false;
    for(int i = 2; i <= x/i; i++){
        if(x%i==0) return false;
    }
    return true;
}
```

> 时间复杂度:$O(\sqrt{n})$





### 素数筛

> 求1~n中的素数.

#### 埃氏筛

枚举2~$\sqrt n$,如果当前数是没被筛过,就以当前数的倍数去筛掉合数.

```c++
int primes[N];
bool not_prime[N];
int cnt;
void count_prime(int n){
    for(int i = 2; i <= n/i; i++){
        if(! not_prime[i]){
            primes[cnt++] = i;
            if((long long)i*i > n) continue; 
            for(int j = i*i; j <= n; j += i){
                primes[j] = true;
            }
        }
    }
}
```

>  时间复杂度$O(n\log\log n)$

#### 线性筛(欧拉筛)

##### 线性筛1~n中的素数

保证每一个合数只被该合数的最小质因数筛掉.

```c++
int primes[N];
bool not_prime[N];
int cnt;
void count_prime(int n){
    for(int i = 2; i <= n; i++){
        if(! not_prime[i]){
            primes[cnt++] = i;
        }
        for(int j = 0; primes[j] <= n/i;j++){
            not_prime[primes[j]*i] = true;
            if(i%primes[j] == 0) break;
        }
    }
}
```

> 时间复杂度:$O(n)$

##### 筛法求1~n中的欧拉函数

设phi[i]表示第i个数的欧拉函数.

若i为素数,显然ph[i]= $i-1$,否则则有
$$
phi[i*primes[j]]=
\begin{cases}
primes[j]*phi[i],\quad primes[j] \mid  i\\
phi[i]*(primes[j]-1), \quad primes[j] \nmid  i
\end{cases}
\tag{1}
$$

>证明如下:
>$$
>设p_i=primes[i]行筛法时，若p_j \mid i,则p_j是i*p_j的最小质因数,\\又phi[i]包含i*\frac{p_1-1}{p_1}*\dots*\frac{p_j-1}{p_j},根据定义只需乘上p_j\\
>否则，需要乘上p_j/p_j(p_j-1)=(p_j-1)
>$$

```c++
const int N = 1e5 + 10;
int pri[N],phi[N],cnt;
bool st[N];
void get_phi(int n){
    phi[1] = 1; //根据定义
    for(int i = 2; i <= n; i++){
        if(!st[i]){
            pri[cnt++] = i;
            phi[i] = i - 1;//1~p中与p互质的数为p-1个
        }
        for(int j  = 0; pri[j]<=n/i;j++){
            st[pri[j]*i] = true;
            if(i%pri[j] == 0){
                phi[i*pri[j]] = phi[i]*pri[j];//只需在乘p
                break;
            }
            phi[i*pri[j]] = phi[i]*(pri[j] - 1);//再乘p* (p-1)/p=p-1
        }
    }
}
```



##### 筛法求1~n中的约数个数

用$d_i$表示i的约数个数,$num_i$表示i的最小质因数出现次数.

$$
由约数个数定理可得d_i=\prod_{i=1}^{m}(c_i + 1),其中c_i为p_i出现次数。 \\
当i为质数时，d_i=2,num_i = 1\\
考虑k=i*prime[j],若prime[j] \mid i,则nums_k=nums_i+1,d_k=d_i/num_k*(num_k+1)\\
若prime[j] \nmid i,则num_k=1,d_k = d_i*(num_k+1) = d_i*2
$$

```c++
int primes[N],d[N],num[N],cnt;
bool st[N];
void get_fact_count(int n){
    d[1] = 1;
    for(int i = 2;i <= n; i++){
        if(!st[i]){
            primes[cnt++] = i;
            num[i] = 1; d[i] = 2;
        }
        for(int j = 0;primes[j] <= n/i; j++){
            int p = primes[j];
            int k = p*i;
            st[k] = true;
            if(i%p==0){
                num[k] = num[i] + 1;
                d[k] = d[i]/num[k]*(num[k] + 1);
            }else{
				num[k] = 1; d[k] = d[i]<<1                
            }
        }
    }
}
```



##### 线性筛1~n中每个数的约数和

记 $f_i表示第i个数的约数和，g_i表示第i个数的最小质因子和$

```c++
int primes[N],f[N],g[N];
bool st[N];
int cnt;
void pre(int n ){
    f[1] = g[1] = 1;
    for(int i = 2;i <= n; i++){
        if(!st[i]){
            primes[cnt++] = i;
            f[i] = g[i] = i + 1; //质数显然约数和为i+1
        }
        for(int j = 0;primes[j] <= n/i; j++){
            int m = i*primes[j];
            st[m] = true;
            if(i%primes[j] == 0){
                //需要增加p^k个，这样写不用统计质数个数
                g[m] = 1 + g[i]*primes[j];
                f[m] = f[i]/g[i]*g[m]; //根据约数和定理
                break;
            }
            g[m] = primes[j] + 1;//m的最小质因数之和为primes[j]+1
            f[m] = f[i]*g[m]; //在i个基础上乘上贡献
        }
    }
}
```
