### 模板

#### 求某个数x的欧拉函数

1~n中与n互质的数的个数称为 $Eluer函数,记作\phi(n)$

$$
\phi(n)=n*\frac{p_1-1}{p_1}*\frac{p_2-1}{p_2}*\dots*\frac{p_{\phi n}-1}{p_{\phi}}
$$

$$
用容斥原理证明如下:\\
\phi(n)=n-\frac{n}{p_1}-\frac{n}{p_2}-\dots-\frac{n}{p_{\phi(n)}} + \frac{n}{p_1p_2} + \dots +\frac{n}{p_{\phi(n)-1}p_{\phi(n)}} -\dots \\
=n*\frac{p_1-1}{p_1}*\frac{p_2-1}{p_2}*\dots*\frac{p_{\phi n}-1}{p_{\phi}}
$$

```c++
int get_euler(int n){
    int ans = n;
    for(int i = 2; i <= n/i; i++){
        if(n%i==0){
            ans = ans/i*(i-1);
            while(n%i==0) n/=i;
        }
    }
    if(n>1) ans = ans/n*(n-1);
    return ans;
}
```

#### 筛法求1~n中的欧拉函数

设phi[i]表示第i个数的欧拉函数.

若i为素数,显然ph[i]= $i-1$,否则则有
$$
phi[i*primes[j]]=
\begin{cases}
primes[j]*phi[i],\quad primes[j] \mid  i\\
phi[i]*(primes[j]-1), \quad primes[j] \nmid  i
\end{cases}
\tag{1}
$$

>证明如下:
>$$
>设p_i=primes[i]行筛法时，若p_j \mid i,则p_j是i*p_j的最小质因数,\\又phi[i]包含i*\frac{p_1-1}{p_1}*\dots*\frac{p_j-1}{p_j},根据定义只需乘上p_j\\
>否则，需要乘上p_j/p_j(p_j-1)=(p_j-1)
>$$

```c++
const int N = 1e5 + 10;
int pri[N],phi[N],cnt;
bool st[N];
void get_phi(int n){
    phi[1] = 1; //根据定义
    for(int i = 2; i <= n; i++){
        if(!st[i]){
            pri[cnt++] = i;
            phi[i] = i - 1;
        }
        for(int j  = 0; pri[j]<=n/i;j++){
            st[pri[j]*i] = true;
            if(i%pri[j] == 0){
                phi[i*pri[j]] = phi[i]*pri[j];
                break;
            }
            phi[i*pri[j]] = phi[i]*(pri[j] - 1);
        }
    }
}
```

### 欧拉定理

若a,m互质，则有 $a^{\phi(m)} \equiv 1 \pmod m$

> 证明如下：
> $$
> 设a的即约剩余系为Z^{'},因为m与a互质，所以a*Z^{'}中的数在模m下也互不相同。\\因此Z^{'} \equiv m*Z^{'}.设b_i \in Z^{'},则 \prod_{i=1}^{\phi(m)}b_i\equiv\prod_{i=1}^{\phi(m)}b_i*a\equiv a^{\phi(m)}\prod_{i=1}^{\phi(m)}b_i。\\
> 两边同时消去\prod_{i=1}^{\phi(m)}b_i,得a^{\phi(m)} \equiv 1 \pmod m
> $$

若m为质数，则有$a^{m-1} \equiv 1$,即费马小定理。

### 扩展欧拉定理

用于求解 $a^b \mod m$中b过大，超过 long long范围，因此用欧拉降幂。
$$
a^b \mod m=
\begin{cases}
a^b,&\quad b <  \phi(m)\\
a^{b \mod \phi(m)\ +\  \phi(m)}, &\quad b \ge  \phi(m)
\end{cases}
\tag{1}
$$
