### 定义

中国剩余定理用于求解如下形式的一元线性同余方程组(其中$n1,\dots,n_k两两互质$)
$$
\left\{ 
\begin{array}{c}
    x \equiv a_1 \pmod {n_1} \\ 
    x \equiv a_2 \pmod {n_k} \\
    \vdots \\
    x \equiv a_k \pmod {n_k}
\end{array}
\right.
$$

### 算法流程

1. 计算所有模数的积 n**(注意没有取模)**；
2. 对于第i个方程: 
   1. 计算$m_i =\frac{n}{n_i}$
   2. 计算$m_i在模n_i意义下的逆元m_i^{-1}$
   3. 计算 $c_i=m_i*m_i^{-1}(不要对n_i取模)$
3. 方程组在模n意义下的唯一解为: $x= \sum_{i=1}^{k} a_i c_i \pmod n,其中a_i为余数$

> 证明：
> $$
> \begin{aligned}
> &需要证明对于任意i=1,2,\dots,k满足x \equiv a_i \pmod {n_i}\\
> &当i \ne j时，m_i \mod n_j \equiv 0 \pmod {n_j}\\
> &当i=j时，m_i *m_i^{-1} \equiv 0 \pmod {n_i}\\
> x&= \sum_{i=1}^{k} a_i c_i \pmod {n_i}\\
> &=a_im_im_i^{-1} \pmod {n_i} \\
> &=a_i\\
> &即对于任意i=1，2，\dots,k,总是满足x \equiv a_i \pmod {n_i}
> \end{aligned}
> $$
>

```c++
typedef long long ll;
ll CRT(int k,ll* a,ll* n){
    ll mul = 1;
    for(int i = 0;i < k; i++) mul=mul*n[i];
  	ll ans = 0;
    for(int i  =0;i < k; i++){
        ll m = mul/n[i];
        exgcd(m,n); 
        ans = (ans + a*x%mul*m)%mul;
    }
    return (ans%mul + mul)%mul;
}
```



注意这个写法虽然简单但可能会被卡。

### 扩展：模数不互质的情况下

对于模数不互质的情况，可以**基于方程合并的思想**，将两个方程合并为一个方程，依次进行处理。

#### 两个方程的情况

$$
\left\{ 
\begin{array}{c}
    t \equiv a_1 \pmod {m_1} \\ 
    t \equiv a_2 \pmod {m_2} \\
\end{array}
\right.
$$

$$
\begin{aligned}
&\therefore  a_1 \pmod {m_1} \equiv  a_2 \pmod {m_2}\\
&\therefore  a_1*+ m_1*x_1 = a_2 + m_2*x_2\\
&\therefore  m_1*x_1 -  m_2*x_2 = a_2 - a_1 \\
&由裴蜀定理定理知:当gcd(m1,m2) \not{|}\ (a_2-a_1)时无解。\\
&否则可得通解x = x_0*\frac{a2-a1}{gcd(m_1,m_2)} +  \frac{m_2}{gcd(m_1,m_2)}*k\\
&(其中x_0为扩欧求出的裴蜀定理方程的特解)\\
&令x' =  x_0*\frac{a2-a1}{gcd(m_1,m_2)}\\
\therefore t &= a_1 + m_1*x\\
&=a_1 + m_1*x' +  \frac{m_2}{gcd(m_1,m_2)}*k)\\
&=m_1*x' + a_1  + lcm(m_1,m_2)*k\\
&\therefore t \equiv m_1*x' + a_1 \pmod {lcm(m_1,m_2)}

\end{aligned}
$$

#### 多个方程的情况

按照上面的步骤一一合并即可。

```c++
using i128 = __int128;
i128 x,y;

ll EXCRT(){
   i128 m1 = m[1],r1 = r[1]; //m数组存储模数，r数组存储余数
   for(int i = 2;i <= n; i++){
       i128 m2 = m[i],r2 = r[i];
       ll d = exgcd(m1,m2);
       ll c = r2 - r1;
       if(c%d) return -1; //无解
       x *= c/d; ll tx = m2/d;
       x = (x%tx+tx)%tx; //将x转化为最小的非负整数解
       r1 = m1*x + r1; //合并方程，新的余数为m1*x + r1
       m1 *= m2/d; //合并方程，新的模数为lcm(m1,m2)
   }
    return r1%
}
```
