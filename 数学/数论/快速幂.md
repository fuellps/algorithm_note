### 模板

> 给定a,b,m，计算 $a^b \mod m$

基于二进制的快速幂：将b进行二进制分解，假使 $d_i$表示b中的二进制第i位数。则
$$
a^b \mod m = a^{2^{d_1 + d_2 + d_3 + \dots + d_n}} \mod m \\
=a^{2^{d_1}}*a^{2^{d_2}}*a^{2^{d_3}}*\dots*a^{2^{d_n}} \mod m\\
=a^{2^{d_1}}\pmod m*a^{2^{d_2}}\pmod m*\dots *a^{2^{d_n}}\pmod m
$$

```c++
typedef long long ll;
ll qpow(ll a, ll b, int m){
    ll res = 1;
    while(b){
        if(b&1) res = res*a%p;
        b>>=1;
        a=a*a%p; 
    }
    return res;
}
```
