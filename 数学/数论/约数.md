### 试除法求约数

①:暴力做法:枚举1~x中的所有数,判断是否能够整除x.

②:枚举1~$\sqrt n$的数即可.若$d|x,则\frac{x}{d}|x$.

```c++
vector<int> factor(int x){
    vector<int> result;
    for(int i = 1;i <= x/i; i++){
        if(x%i==0){
            result.push_back(i);
            if(i != x/i) result.push_back(x/i);
        }
    }
    return result;
}
```

> 时间复杂度 $O(\sqrt n)$

### 求约数个数

用$d_i$表示i的约数个数,$num_i$表示i的最小质因数出现次数.

#### 约数个数定理

> 若n=$\prod_{i=1}^{m}p_i^{c_i}$,则$d_i=\prod_{i=1}^{m}(c_i + 1)$
>
> 证明:因为$p_i^{c_i}$的约数个数有$c+1$个,根据乘法原理可知n的约数个数为$\prod_{i=1}^{m}(c_i + 1)$

```c++
void countFactor(int x){
    unordered_map<int,int> pri;
	for(int i = 2; i <= x/i;i++){
        if(x%i == 0){
            pri[x] += 1;
        }
    }
    if(x > 1) pri[x] += 1;
    ans = 1;
    for(auto entry : pri){
        ans *= entry.second;
    }
    cout << "约数个数为: "<< ans << endl;
}
```

> 时间复杂度:$O(\sqrt n)$
