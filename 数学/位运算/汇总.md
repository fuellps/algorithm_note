### 相关性质

#### 异或

- 异或的本质是**不进位加法**
-  $ x \oplus x = 0, 0 \oplus x = x$



### 等式

- 加法恒等式

$$
\begin{aligned}
&a + b = (a|b) +(a \& b) \\
&a + b = (a\oplus b) + 2(a\&b)  \qquad \because a|b = (a \oplus b) + (a \&b)
\end{aligned}
$$

> 例题:给定t组数字,判断是否存在两个非负整数p,q,满足x= p + q,y =p$\oplus$q.
>
> 满足条件输入"Yes”,不满足条件输出"No”

  由于p,q均为非负整数,则需要满足以下条件:
  ①.x >= y
  ②:(x-y)%2 == 0
  ③:p&q与p^q没有任何交集
