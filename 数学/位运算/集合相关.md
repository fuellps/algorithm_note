## 集合相关

$1.计算二进制中1个个数,即集合的大小$

```java
Integer.bitCount(x);
```

$2.二进制的长度$

```java
32-Integer.numberOfLeadingZeros(x);
```

$3.集合最大的元素:即为二进制长度-1$

```java
31-Integer.numberOfLeadingZeros(x);
```

$4.集合最小的元素:即为二进制中尾随0的个数$

```java
Integer.numberOfTrailingZeros(x);
```

5.$删除集合最小元素,即去掉集合最后的1$

```java
s&s-1
```

$6.计算只包含最小元素的子集,即第一位是1,其他位是0,叫做lowbit$

> 如果想获取第一位是0的话,将集合取反再做lowbit就行

```java
x&-x
```



## 遍历集合

设元素范围从0到n-1,枚举范围中的元素i,判断元素是否在集合s内.

```java
for(int i = 0;i < n; i++){
    if((s>>i & 1) == 1){ //i在s中
        //处理i的逻辑
    }
}
```

直接遍历s中的最小元素:不断计算集合最小元素,去掉最小元素,直到集合为空.

```java
for(int t = s; t > 0; t &= t - 1){
    int i = Integer.numberOfTrailingZeros(t);
    //处理i的逻辑
}
```



## 枚举集合

### 枚举所有集合

设元素范围从0到n-1,从空集枚举到全集U:

```java
for(int s = 0;s < 1 << n; s++){
    //处理s的逻辑
}
```

### 枚举所有非空子集

设集合为s,$从大到小$枚举s的所有$非空$子集sub:

```java
for(int sub = s; sub > 0; sub = (sub - 1)&s){
    //处理sub的逻辑
}
```

## 枚举子集(包含空集)

```java
int sub = s;
do{
    sub = (sub-1)&s;
}while(sub != s);
```

>  当s为空集(0)时,减1得到-1,-1的二进制位111111..., -1&s = s.因此当sub=s时说明以及遍历完所有的子集
