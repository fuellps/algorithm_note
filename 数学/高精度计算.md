### 存储

高精度数字利用字符串存储,每一个字符表示数字的一个十进制位。

> 读入字符串时，数字最高位在字符串首（下标小的位置）。但是习惯上，下标最小的位置存放的是数字的 $最低位$，即存储反转的字符串。

### 高精度加法

数据范围 $0 \le a \le 10^{500}, 0 \le b \le 10^{500}$

```c++
#include <bits/stdc++.h>
using namespace std;
const int N = 510;
struct BitNum{ 
    int v[N];
    int len;
}a,b,c;
int la,lb,lc;
void read(BitNum& x,string& s){
    int n = s.size();
    for(int i = n  - 1; ~i; i--) x.v[x.len++] = s[i] - '0';
}
void add(BitNum& a, BitNum& b, BitNum& c){
    c.len = max(a.len,b.len);
    for(int i = 0;i < c.len; i++){
         c.v[i] += a.v[i];
         c.v[i] += b.v[i];
         if(c.v[i] > 9){
             c.v[i+1] += c.v[i]/10
         	c.v[i] %= 10;
         }
    }
    if(c.v[c.len]) c.len++; //判断最后是否有进位
}
int main(){
    string s1,s2; cin >> s1 >> s2;
    read(a,s1);read(b,s2); add(a,b,c);
    for(int i = c.len - 1;~i;i--)
        cout << c.v[i];
}
```
