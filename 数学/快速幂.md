### 模板

快速幂基于二进制拆分和倍增思想。
$$
对于指数n，对其进行二进制拆分，\\
\begin{aligned}
a^n&=a^{2^{b_0} + 2^{b_1} + 2^{b_2} + \dots + 2^{b_m}}\\
&=a^{2^{b_0}}*a^{2^{b_1}}*a^{2^{b_3}}*\dots *a^{2^{b_m}}\\
&其中若b_i=0,则a^{2^{b_i}}=1.
\end{aligned}\\
\\
所以可以处理出a^0,a^1,a^2,a^4...a^m，\\
若b_i=1,则res*=a^{2^i}.
$$

```c++
ll qpow(ll a,int b,int mod){
    ll res= 1;
    while(b){
        if(b&1) res = res*a%mod;
        a=a*a%mod;
        b>>=1;
    }
    return res;
}
```

#### 64位乘法

对于64位乘法，结果会超过64位，但如果对一个64位以内的数进行取模，可以基于快速幂的思想进行计算。
$$
对于乘数b，对其进行二进制拆分，\\
\begin{aligned}
a*b&=a*(2^{b_0} + 2^{b_1} + 2^{b_2} + \dots + 2^{b_m})\\
&=a*{2^{b_0}}+a^{2^{b_1}}+a*{2^{b_3}}+\dots +a^{2^{b_m}}\\
&其中若b_i=0,则a*{2^{b_i}}=0.
\end{aligned}\\
\\
所以可以处理出a，2a,4a,8a,\dots,2^ma\\
若b_i=1,则res+={2^i}a.
$$

```c++
ll mul(ll a,ll b,ll p){
	ll res = 0;
	while(b){
		if(b&1) res = (res + a)%p;
		a = (a+a)%p;
		b>>=1;
	}
	return res;
}

```
