### 集合的并集




$$
\Bigl|\bigcup_{i=1}^n A_i\Bigr|
= \sum_{i=1}^n |A_i|
- \sum_{1 \le i < j \le n} |A_i \cap A_j|
+ \sum_{1 \le i < j < k \le n} |A_i \cap A_j \cap A_k| \\
- \cdots
+ (-1)^{\,n-1} \bigl|A_1 \cap A_2 \cap \cdots \cap A_n\bigr|.
$$

即
$$
\Bigl|\bigcup_{i=1}^n A_i\Bigr|
= \sum_{k=1}^n (-1)^{\,k-1}
  \;\sum_{1 \le i_1 < \cdots < i_k \le n}
  \bigl|A_{i_1} \cap \cdots \cap A_{i_k}\bigr|.
$$

> 给定一个整数n和m个不同的质数p1,p2...pm.
>
> 求1~n种能被p1,p2...pm种的至少一个数整除的数有多少个。
>
> 其中$m \le 16,n,p_i \le 10^9$

```c++
int get_ans(){
    int res = 0;
    for(int i = 1;i < 1<<m; i++){
        ll t=  1;
        int sign = -1;
        for(int j =0;j < m; j++){
            if(i>>j&1){
                t *= a[j];//因为是素数，所以乘积就是最小公倍数
                if(t > n){ //特判，防止素数累乘过大
                 	t = 0;
                    break;
                }
                sign = -sign;
            }
        }
        if(t) res += n/t*sign;
    }
    return res;
}
```

### 集合的交集


$$
\left|\bigcap_{i=1}^n A_i\right|
= |U|
- \sum_{k=1}^n (-1)^{k-1}
  \sum_{1\le i_1<\cdots< i_k\le n}
    \bigl|A_{i_1}^c \cap \cdots \cap A_{i_k}^c\bigr|.
$$
