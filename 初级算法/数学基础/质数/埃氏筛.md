从2开始枚举,每次筛掉遇到的素数.

```java
static int N = 1_000_001;
static boolean[] vi = new boolean[N];
static int cnt;
static void getPrimes(int n){//得到1~n范围内的素数
    vi[1] = true;
    for(int i = 2; i <= n; i++){
        if(!vi[i]){
            if(i > n/i) continue;//注意下面代码i*i可能会溢出.
            for(int j = i*i; j <= n; j+=i){
                vi[j] = true;
            }
        }
    }
}
时间复杂度O(nloglogn)
```
