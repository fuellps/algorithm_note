### 基础概念

根据原数组得出的差分数组求前缀和后的每个元素就等于原数组每个元素.

差分数组常用于在一段区间内加/减某个数.差分数组d[i]加上一个数x,可以认为对于>=d[i]的数都加上x.

>  **$在差分数组d[i]上加/减1个数,相当于在原数组一段后缀(>=i)上加/减一个数$**



例题:要使数组nums成为数组target的最小操作次数.每次可以对于任意子数组加/减1.

$令数组a[i] = target[i] - nums[i],则问题等价求使得a数组全为0的最小操作次数$



$问题等价于在任意两个端点diff[i],diff[j]加上/减去1$

$对于任意diff[i] > 0,一定存在一个diff[j] = -diff[i],这样求前缀和才不会一直累加.$

$所以最少操作次数一定等价于差分数组中正数之和$



### 写法

一般有两种写法.

$一.开一个和值域有关的数组进行差分$

$二:利用平衡树进行差分$



### 区间加值相关

如果只涉及到区间统计问题,那么区间存在可以视为在这段区间的数字上都加上1.这可以用差分进行解决.

$具体的,如果遍历求得前缀和s > 0,说明该点是在区间范围内的.$

$若s>1,则说明当前点出现区间重叠.$

$若s==0,则说明当前点没有位于区间内.$

> 注意:如果某些题要求合并重叠区间.如果使用差分的话,需要使距离*2,考虑这样的例子:[1,2],[3,4].这段区间在[1-4]都是连续的,因为差分会将连续1合并,所以$\times$2后则会保证它们之间的距离变为2,就不会合并了.



区间合并所有重叠区间:

```java
//区间为[start,end]
Map<Integer,Integer> dict = new HashMap<>();
	for(int[] q : interval){
        dict.merge(q[0]*2,1,Integer::sum);//避免合并[1,3] [4,5]等区间
        dict.merge(q[1]*2 + 1,-1,Integer::sum);
    }
	int s = 0, last = -1; //区间重叠个数 当前区间的左端点 
	List<int[]> ans = new ArrayList<>(); 
	for(Map.Entry<Integer,Integer> entry : dict.entrySet()){
        s += entry.getKey();
        if(s == 0 && last != -1){ //到达区间右端点(不包含)
            ans.add(new int[]{last/2,entry.key()/2});
            last = -1;
        }
        if(s > 0 && last == -1){//区间刚开始
            last = entry.getKey();
        }
    }
```

区间合并且需要将区间重叠部分视为新的区间.

```c++
	map<int,int> dict;
//区间为[start,end)
    for(int[] q : interval){
            dict[q[0]] += q[2];
            dict[q[1]] -= q[2];
    }
	vector<vector<int>> ans;
	int s = 0,last = -1;
    for(auto& [k,v] : dict){
		 	int news = s + v;
            vector<int> t(3);
            t[0] = last,t[1] = k,t[2] = s;
            if(news > 0 && last != -1){ //区间有重叠
                ans.push_back(t);
                last = k;//当前端点是其他区间的左端点
            }else if(news == 0 && last != -1){ //已经到达区间右端点(不包含)
                ans.push_back(t);
                last = -1;
            }
            if(news > 0 && last == -1){//一个区间的开始且没有左端点
                last = k;
            }
            s = news;
    }
```





### 注意事项

##### 对于区间可以有浮点数问题

若所求区间交点可以不为整数的话,应该将交点区间进行扩大,这样就能避免浮点数的问题.
