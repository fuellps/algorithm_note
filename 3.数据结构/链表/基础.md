### 常见错误

$ \$1 \ 没有判断是否头节点为空就从头节点的下一个元素开始遍历$

### 1.链表的遍历

```c++
while(head){ //当链表不空时
    //执行操作
    head = head->next; //遍历下一个节点
}
```



### 2.删除节点

一般设置虚拟节点.因为给定的头节点可能改变.

```c++
核心：
    head->next = head->next->next
```



$删除值等于val的节点

```c++
ListNode* dummy = new ListNode(-1);
dummy->next = head;
ListNode* cur = dummy;
for(ListNode* p = head; p; p = p.next){
    if(p == val){
        cur->next = p; //虚拟节点尾节点的下一个节点指向当前节点
        cur = cur->next; //改变尾指针
    }
}
cur->next = nullptr; //注意不要忘记要将尾节点下一个节点指空
return dummy->next; //dummy->next即为删除后的新的链表
```





### 3.插入节点

在p节点**之后**插入node节点.

$node->next = p->next, p->next = cur.$

```c++
// 以插入排序链表为例:
ListNode* lastSorted = head; //上一个已经有序的节点指针
ListNode* p = head->next; //注意判断链表长度是否大于等于1;p指向未排序的节点
while(p){ //还有未排序的节点
    ListNode* nxt = p->val; //下一个节点
    if(lastSorted->val <= p->val){
        lastSorted = p;
    }else{
        ListNode node;
        for(ListNode cur = dummy; cur != lastSorted; cur = cur>next){
            //找到第一个大于等于p节点值的指针
            if(cur->node->val >= p->val){
                node = cur;
                break;
            }
        }
        p->next = node->next;
        node->next = p;
        //注意:这里还需要改变最后一个排序好的节点的后继节点,不然会出现环.
        lastSorted->next = nxt;
    }
    p = nxt;
}
```

### 4.链表反转

以k个一组翻转链表为例.

```c++
   ListNode* reverseKGroup(ListNode* head, int k) {
        if(k == 1 )return head;
        ListNode* dummy = new ListNode(-1);
        dummy->next = head;
        ListNode *p = dummy,*cur,*nxt;
        while(p != nullptr){
            ListNode* tmp = p;//tmp位于要交换的起始节点的前驱
            //移动到要交换的终止节点
            for(int i  = 0;i < k && p != nullptr; p = p->next, i++);
            if(p == nullptr) break;
            cur = tmp->next;
            //记录终点位置
            ListNode* pre = p->next,*end = p->next;
            while(cur != end){
                nxt = cur->next;
                cur->next = pre;
                pre = cur;
                cur = nxt;
            }
            //p指向下一组要交换的节点的前驱节点.翻转后fantmp->next为翻转前的起始节点.翻转后为下一组要交换的节点的前驱节点
            p = tmp->next;
            //tmp的下一个节点指向翻转后的头节点
            tmp->next = pre;
        }
        return dummy->next;
    }

```

### 5.实现常见结构

#### LRU(Least Recently Used) cache 

- 利用双链表+哈希表实现
- 双链表记录key和对应的值，便于删除结点时能删除哈希表中对应的值。
- 将结点移动到头结点时要先删除原结点
