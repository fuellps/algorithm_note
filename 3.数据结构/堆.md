### 堆基础

一般使用完全二叉树实现。

下面堆以下标从1开始的小根堆为例。

对于第i号节点，左儿子下标为2i,右儿子下标为2i+1

主要支持两种操作:push(x):将x加入堆中。 pop():弹出并返回堆顶元素



### 模板

```c++
struct Heap{
  int si;
    int heap[N];
    void push(int x){
        heap[++si] = x;
        int i = si;
        while(i/2 && heap[i>>1] > heap[i]){
            swap(heap[i],heap[i>>1]);
            i >>=1;
        }
    }
    
    int pop(){
        int x = heap[1];
        swap(heap[1],heap[si--]);
        int i = 1,j=2;
        while(j <= si){
            if(j+ 1 <= si && heap[j+1] < heap[j]) j++;
            if(heap[i] < heap[j]) break;
            swap(heap[i],heap[j]);
            i = j;
            j = i<<1;
        }
        return x;
    }
    
    int top(){
    	return heap[1];
	}
};
```

### 对顶堆

###### 维护第k大

**动态维护**序列 **第k大的数**.由一个小根堆和一个大根堆组成。

具体而言，假设第大的数为x,小根堆维护 $a_i \ge x$的值，大根堆维护 $a_j \lt x$的值.

1. **插入**： $小根堆为空或小根堆堆顶 \ge 当前元素,插入到小根堆,否则插入到大根堆.$
2. **维护**: 小根堆大小大于k时,不断弹出堆顶到大根堆.小于k时不断弹出大根堆堆顶到小根堆.
3. **查询**:**小根堆堆顶**即为第k大的数
4. **删除**: 删除第k大的数,直接弹出小根堆堆顶.

###### 维护第k小

**维护第k小同理,只需交换大根堆和小根堆即可.**
