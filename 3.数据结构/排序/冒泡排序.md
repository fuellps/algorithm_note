每一轮扫描,交换相邻元素最大/最小的元素,一轮交换就会使数组未排序的最末尾元素有序.执行n-1轮即可完成排序.

考虑优化的话,可以定义一个变量表示是否进行交换.如果一轮中没有交换即数组中已经有序了

```c++
//使数组成非递减序 
bool change = true;
while(change){
    change = false;
    for(int i = 0;i + 1< n; i++){
        if(nums[i] > nums[i+1]){
            change = true;
            swap(nums[i], nums[i+1]);
        }
    }
    n
}
```
