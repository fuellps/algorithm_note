遍历数组,对于位于下标i处,假设$\sum_{j = 0}^{i-1}nums[i](i > 0)$已经有序.

此时对于下标i处只需找到一个合适的位置插入即可.

```c++
//使数组非递减排序
for(int i = 1;i < n; i++){
    int t = nums[i];
    int j = i;
    //前1个数大于当前数,前一个数覆盖当前位置.
    for(;j > 0 &&  nums[j-1] > nums[j]; j--){
        nums[j] = nums[j-1];
    }
    //将t插入合适的位置
    nums[j] = t;
}
```
