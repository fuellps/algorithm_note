### 维护高度为x,宽度为y的子矩阵最大,最小值

可用通过预处理宽度为y的每一行的最值,存放在一个二维数组中.

然后通过求出的二维数组处理高度为x的最值,存放在最值数组中.

$则resmx[i][j] 其中(i >= x, j >= x)就是以(i,j)为右下角,高度为x,宽度为y的子矩阵最大值,最小值同理$

```c++
const int MAXN = 1e5 + 10;
const int N,M; 
int mnq[MAXN],mxq[MAXN];
int ll,lr,ul,ur; //ll,lr对应维护最小值的队列指针. ul,ur对应维护最大值的队列指针
int g[N][M],
mn[N][M],mx[N][M], //存储每一行对应宽度(长度)为y的最值
resmn[N][M],resmx[N][M];//存放高度为x,宽度为y的最值

//下面代码求高度为x,宽度为y的子矩阵最值
void get_extreme(int x,int y){
    //求出每一行对应的最值
for(int i = 0;i < n; i++){
    ll = lr= ul = ur = 0;
    for(int j = 0;j < m; j++){
        //求最小值
        while(ll < lr && g[i][mnq[lr-1]] >= g[i][j]){
            lr--;
        }
        if(ll < lr && mnq[ll] == j - y) ll++;
        mnq[lr++] = j;
        
        //求最大值
        while(ul < ur && g[i][mxq[ur - 1]] <= g[i][j]){
            ur--;
        }
        if(ul < ur && mxq[ul] == j - y) ul++;
        mxq[ur++] = j;
        
        mn[i][j] = g[i][mnq[ll]];
        mx[i][j] = g[i][mxq[ul]];
    }
}

for(int j = 0;j < m; j++){
    ll = lr = ul = ur = 0;
    for(int i = 0;i < n; i++){
        while(ll < lr && mn[mnq[lr - 1]][j] >= mn[i][j]){
            lr--;
        }
        if(ll < lr && mnq[ll] == i - x) ll++;
        mnq[lr++] = i;
        
        
        while(ul < ur && mx[mxq[ur - 1]][j] <= mx[i][j]){
            ur--;
        }
        if(ul < ur && mxq[ul] == i - x) ul++;
        mxq[ur++] = i;
        resmn[i][j] = mn[mnq[ll][j];
		resmx[i][j] = mx[mxq[ul]][j];
    }
}
//此时resmn[i][j]就是对应的x*y子矩阵最小值. resmx[i][j]就是对应x*y子矩阵最大值
}
```
