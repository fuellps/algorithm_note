### 一:单调队列维护窗口长度为k的子数组最大值

> 对于维护最大值,应该保持队列递减状态.这样队首元素就是最大值.

为什么要这样做呢? 在窗口滑动的过程中,扩大窗口时,如果窗口内有一些数比要进来的数要小,那么就一定不会再成为最大元素了.因为刚进来的数比窗口内的数晚出去,还比窗口内的数大.

> 当一个人比你晚来,还比你强大,你就永久不可能成为最强的那个人.

```c++
//维护长度为k的滑动窗口最大值
const int N = 1e5 + 10;
int mxq[N];
int l,r;
int k;
for(int i = 0;i < n; i++){
    while(l < r && nums[q[r-1]] <= nums[i]){//队列非空,窗口内有元素比要进来的元素小
        r--;
    }
    if(l < r && q[l] == i - k) l++; //队列有元素,且队首元素过时,出队.
    q[r++] = i; //当前数入队
}
```



### 二:单调队列维护窗口长度为k的子数组最小值

与求最大值类似,这里维护递增的队列.$即当队列中存在元素且队尾元素大于等于入队元素时,让队尾元素出队$

为什么要这样做呢? 在窗口滑动的过程中,扩大窗口时,如果窗口末尾内有一些数比要进来的数要大,那么就一定不会再成为最小元素了.因为刚进来的数比窗口末尾内的数更晚出去,还比窗口内的数更小.

```c++
const int N = 1e5 + 10;
int mnq[N];
int l,r;
int k;
//....
for(int i =0 ;i < n; i++){
    while(l < r && nums[q[r-1]] >= nums[i]){//队列非空,窗口内有元素比入队元素大
        r--;
    }
    if(l < r && q[l] == i - k) l++; //队列非空,队首元素过时,出队
    q[r++] = i; //d
}
```



### 三:单调队列维护子数组绝对差小于某个数的最长长度

子数组长度越大,绝对差就可能越大,具有单调性,可以进行滑动窗口.

这类属于求最长的滑动窗口,在while循环外统计答案.

用一个单调队列维护最小值$下标$,一个单调队列维护最大值$下标$,进行更新即可.

```python
minq,maxq,left = deque(),deque(),0
for right,x in enumerate(nums):
    # 维护最小值模板
    while minq and nums[minq[-1]] >= x:
        minq.pop()
    minq.append(right)
    #维护最大值模板
    while maxq and nums[maxq[-1]] <= x:
        maxq.pop()
    maxq.append(right)
    #进行更新:  
    while minq and maxq and nums[maxq[0]] - nums[minq[0]] > limt: #队首元素为最值
 #上面可写出 while minq and nums[maxq[0]] - nums[minq[0]] > limt: 只需判断一个非空即可
    	if minq[0] == left: minq.popleft() 
        if maxq[0] == left: maxq.popleft()
        left += 1
     # 统计答案
    ans = max(ans,right - left + 1) 
```

### 四：维护高度为x,宽度为y的子矩阵最大,最小值

可用通过预处理宽度为y的每一行的最值,存放在一个二维数组中.

然后通过求出的二维数组处理高度为x的最值,存放在最值数组中.

$则resmx[i][j] 其中(i >= x, j >= x)就是以(i,j)为右下角,高度为x,宽度为y的子矩阵最大值,最小值同理$

```c++
const int MAXN = 1e5 + 10;
const int N,M; 
int mnq[MAXN],mxq[MAXN];
int ll,lr,ul,ur; //ll,lr对应维护最小值的队列指针. ul,ur对应维护最大值的队列指针
int g[N][M],
mn[N][M],mx[N][M], //存储每一行对应宽度(长度)为y的最值
resmn[N][M],resmx[N][M];//存放高度为x,宽度为y的最值

//下面代码求高度为x,宽度为y的子矩阵最值
void get_extreme(int x,int y){
    //求出每一行对应的最值
for(int i = 0;i < n; i++){
    ll = lr= ul = ur = 0;
    for(int j = 0;j < m; j++){
        //求最小值
        while(ll < lr && g[i][mnq[lr-1]] >= g[i][j]){
            lr--;
        }
        if(ll < lr && mnq[ll] == j - y) ll++;
        mnq[lr++] = j;
        
        //求最大值
        while(ul < ur && g[i][mxq[ur - 1]] <= g[i][j]){
            ur--;
        }
        if(ul < ur && mxq[ul] == j - y) ul++;
        mxq[ur++] = j;
        
        mn[i][j] = g[i][mnq[ll]];
        mx[i][j] = g[i][mxq[ul]];
    }
}

for(int j = 0;j < m; j++){
    ll = lr = ul = ur = 0;
    for(int i = 0;i < n; i++){
        while(ll < lr && mn[mnq[lr - 1]][j] >= mn[i][j]){
            lr--;
        }
        if(ll < lr && mnq[ll] == i - x) ll++;
        mnq[lr++] = i;
        
        
        while(ul < ur && mx[mxq[ur - 1]][j] <= mx[i][j]){
            ur--;
        }
        if(ul < ur && mxq[ul] == i - x) ul++;
        mxq[ur++] = i;
        resmn[i][j] = mn[mnq[ll][j];
		resmx[i][j] = mx[mxq[ul]][j];
    }
}
//此时resmn[i][j]就是对应的x*y子矩阵最小值. resmx[i][j]就是对应x*y子矩阵最大值
}
```
