### 一:单调队列维护窗口长度为k的子数组最大值

> 对于维护最大值,应该保持队列递减状态.这样队首元素就是最大值.

为什么要这样做呢? 在窗口滑动的过程中,扩大窗口时,如果窗口内有一些数比要进来的数要小,那么就一定不会再成为最大元素了.因为刚进来的数比窗口内的数晚出去,还比窗口内的数大.

> 当一个人比你晚来,还比你强大,你就永久不可能成为最强的那个人.

```c++
//维护长度为k的滑动窗口最大值
const int N = 1e5 + 10;
int mxq[N];
int l,r;
int k;
for(int i = 0;i < n; i++){
    while(l < r && nums[q[r-1]] <= nums[i]){//队列非空,窗口内有元素比要进来的元素小
        r--;
    }
    if(l < r && q[l] == i - k) l++; //队列有元素,且队首元素过时,出队.
    q[r++] = i; //当前数入队
}
```



### 二:单调队列维护窗口长度为k的子数组最小值

与求最大值类似,这里维护递增的队列.$即当队列中存在元素且队尾元素大于等于入队元素时,让队尾元素出队$

为什么要这样做呢? 在窗口滑动的过程中,扩大窗口时,如果窗口末尾内有一些数比要进来的数要大,那么就一定不会再成为最小元素了.因为刚进来的数比窗口末尾内的数更晚出去,还比窗口内的数更小.

```c++
const int N = 1e5 + 10;
int mnq[N];
int l,r;
int k;
//....
for(int i =0 ;i < n; i++){
    while(l < r && nums[q[r-1]] >= nums[i]){//队列非空,窗口内有元素比入队元素大
        r--;
    }
    if(l < r && q[l] == i - k) l++; //队列非空,队首元素过时,出队
    q[r++] = i; //d
}
```



### 三:单调队列维护子数组绝对差小于某个数的最长长度

子数组长度越大,绝对差就可能越大,具有单调性,可以进行滑动窗口.

这类属于求最长的滑动窗口,在while循环外统计答案.
