# 前缀和

## 一维前缀和

$一般定义f[i]表示数组前i个元素的和.\\假设数组下标[i:j](从0开始),则子数组[i:j]之和为:f[j+1] - f[i]$

### 前缀和与哈希表

> 一般涉及到子数组元素之和或者子数组被整数的问题

$记子数组元素和为s,则s= s[r] - s[l],其中l < r$

枚举前缀和r,找到r左边满足条件的前缀和l,则在哈希表中找到前缀和l对应的信息

常见套路:

> ①对于要求子数组内满足一个条件,可以记为1,不满足可以即为-1.则要求子数组内满足条件的元素大于不满足条件的个数的话,即找s[r] - s[l] > 0.



> ②:对于要求子数组内出现两种类型字符出现的比例为num1:num2.即当第一种类型出现num2个,第二种类型出现num1个即为满足条件的子数组.可以将第一种类型的值记为-num2,第二种类型的值记为num1,当且仅当子数组元素之和为0时满足题意条件.



> 对于子数组元素和被子数组长度整除的问题,子数组元素被子数组长度整除相当于子数组内的平均值.如果可以推出子数组平均值较小时,可以枚举子数组平均值,这问题等价于sum[r] - sum[l] /(r-l) = k. 等价于sum[r] - sum[l] = k*(r-l).等价于$sum[r] - k\times r - sum[l] + k \times l = 0$.将每个元素减去子数组平均值,记newSum[r] = sumr[k] - k\*r,则原式等价于 newSum[r] - newSum[l] = 0,因此可以用哈希表查找.



### 距离和

>  **一般涉及到数组中某个元素x到数组其他元素$a_i$之间的距离差. $\sum_{i=1}^{n}|a_i - x|$ **

$基本思路:将数组进行排序,成非递减顺序.求出数组对应的前缀和数组f$

$①对于一个数x,小于x的元素若有j个,则x到它们之间的距离为x*j - f[j]$

$②大于等于x的元素若有k个,则x到它们之间的距离为(f[n] - f[n-k]) -(x*k)$





### 前缀异或和

>  **一般涉及到统计子数组/子串中出现次数为奇偶性问题.**

常见套路:给你一个字符串,要求一个最大的子串,**子串内中字符顺序可以任意排列**,求子串是回文串的最大长度.$这等价于求子串内出现的字符次数至多为1的最长子串$



$解题思路:若所求子串长度为偶数,则相当于求S_{xor_r} \oplus S_{xor_l} = 0 等价于 满足S_{xor_r} =  S_{xor_l}的最小的l$

$若所求子串的长度为奇数,则相当于求S_{xor_r} \oplus S_{xor_l} = 2^k,等价于求满足S_{xor_l}=S_{xor_r}\oplus2^k的最小的了l$



例题:[1542. 找出最长的超赞子字符串](https://leetcode.cn/problems/find-longest-awesome-substring/)

[1915. 最美子字符串的数目](https://leetcode.cn/problems/number-of-wonderful-substrings/)



### 子矩阵

对于子矩阵和问题,可以枚举上下边界,计算每一列之和,将每一列之和视为一个元素.则每一个子数组都对应着1个子矩阵.

## 二维前缀和

### 定义

$定义pre[i][j]表示从mat[1][1]到mat[i][j]所有元素的和$

$对于pre[i][j],可以采用递推的方式求出:\\pre[i][j] = pre[i-1][j] + pre[i][j-1] - pre[i-1][j-1] + mat[i][j]\\对于下标从0开始,需要特判,不妨插入一圈,则原式等价于\\pre[i+1][j+1] = pre[i+1][j] + pre[i][j+1] - pre[i][j] + mat[i][j]$

### 子矩阵和

$对于(r1,c1)为左上角,(r2,c2)为右下角的子矩阵的计算方式为:\\pre[r2][c2] - pre[r2][c1-1] - pre[r1-1][c2] + pre[r1-1][c1-1]\\对于下标从0开始,需要特判,不妨插入一圈,则原式等价于\\pre[r2+1][c2+1] - pre[r2+1][c1] - pre[r1][c2+1] + pre[r1][c1]$

# 	差分

### 基础概念

根据原数组得出的差分数组**求前缀和后**的**每个元素就等于原数组每个元素**.

差分数组常用于在一段区间内加/减某个数.差分数组d[i]加上一个数x,可以认为对于原数组中下标大于等于i的数都加上x.


$$
定义d[i]为数组a的差分数组，则有 \\
d[i] =
\begin{cases}
\text{a[i]}, & \text{i=0}\\
\text{a[i] - a[i-1]}, & \text{i>0}\\
\text{0}, & \text{i=n}\\
\end{cases}
$$


>  **$在差分数组d[i]上加/减1个数,相当于在原数组一段后缀(>=i)上加/减一个数$**



例题:要使数组nums成为数组target的最小操作次数.每次可以对于num任意子数组都加上1或减1.
$$
令数组diff[i] = target[i] - nums[i],则问题等价求使得diff数组全为0的最小操作次数\\
设d为diff的差分数组，
在一段区间加减1，等价于对d的一个端点加1，d的另一个端点减1.\\
设p=\sum_{i=1}^{n}[d[i] > 0],q = \sum_{i=1}^{n}[d[i] < 0]\\

\begin{aligned}
&分类讨论: \\
&1.对0\le i \lt n的两个端点执行加1或减1，让正负相消(贪心想，这一定最优)\\
&2.对0\le i \lt n的一个端点执行加1或减1，对n+1执行加1或减1 \\
\end{aligned} \\
所以总的操作数为 min(p,q) + abs(p-q)=max(p,q)
$$


### 写法

一般有两种写法.

$一.开一个和值域有关的数组进行差分$

$二:利用平衡树进行差分$



### 区间加值相关

如果只涉及到区间统计问题,那么区间存在可以视为在这段区间的数字上都加上1.这可以用差分进行解决.

$具体的,如果遍历求得前缀和s > 0,说明该点是在区间范围内的.$

$若s>1,则说明当前点出现区间重叠.$

$若s==0,则说明当前点没有位于区间内.$

> 注意:如果某些题要求合并重叠区间.如果使用差分的话,需要使距离*2,考虑这样的例子:[1,2],[3,4].这段区间在[1-4]都是连续的,因为差分会将连续1合并,所以$\times$2后则会保证它们之间的距离变为2,就不会合并了.



区间合并所有重叠区间:

```java
//区间为[start,end]
Map<Integer,Integer> dict = new HashMap<>();
	for(int[] q : interval){
        dict.merge(q[0]*2,1,Integer::sum);//避免合并[1,3] [4,5]等区间
        dict.merge(q[1]*2 + 1,-1,Integer::sum);
    }
	int s = 0, last = -1; //区间重叠个数 当前区间的左端点 
	List<int[]> ans = new ArrayList<>(); 
	for(Map.Entry<Integer,Integer> entry : dict.entrySet()){
        s += entry.getKey();
        if(s == 0 && last != -1){ //到达区间右端点(不包含)
            ans.add(new int[]{last/2,entry.key()/2});
            last = -1;
        }
        if(s > 0 && last == -1){//区间刚开始
            last = entry.getKey();
        }
    }
```

区间合并且需要将区间重叠部分视为新的区间.

```c++
	map<int,int> dict;
//区间为[start,end)
    for(int[] q : interval){
            dict[q[0]] += q[2];
            dict[q[1]] -= q[2];
    }
	vector<vector<int>> ans;
	int s = 0,last = -1;
    for(auto& [k,v] : dict){
		 	int news = s + v;
            vector<int> t(3);
            t[0] = last,t[1] = k,t[2] = s;
            if(news > 0 && last != -1){ //区间有重叠
                ans.push_back(t);
                last = k;//当前端点是其他区间的左端点
            }else if(news == 0 && last != -1){ //已经到达区间右端点(不包含)
                ans.push_back(t);
                last = -1;
            }
            if(news > 0 && last == -1){//一个区间的开始且没有左端点
                last = k;
            }
            s = news;
    }
```





### 注意事项

##### 对于区间可以有浮点数问题

若所求区间交点可以不为整数的话,应该将交点区间进行扩大,这样就能避免浮点数的问题.
